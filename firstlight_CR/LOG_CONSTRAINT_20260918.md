# 滚木沿途目标约束

已在本地扩展法术目标约束，支持滚木（`28000011`）。与闪电共用合法落点交集、执行前复核、轨迹规则记录及 PPO 掩码重评分机制。

## 检查区域与目标

- 几何来自已校验资源 `PROJECTILE.LogProjectileRolling`：`ProjectileRange=10100`、`ProjectileRadius=1950`、`ProjectileRadiusY=600`，即前进距离 10.1 格、横向半宽 1.95 格、纵向半厚 0.6 格。
- 按从落点向敌方滚动的完整扫掠矩形检查目标中心；原生坐标 owner 0 朝正 Y，owner 1 朝负 Y。通过原有视角变换映射到模型坐标。
- 默认在矩形四边增加 0.5 格余量，可通过参数调整。因而相对落点的横向距离不超过 2.45 格、向前距离位于 -1.1 至 11.2 格时，目标进入候选区域。落点后方只保留滚木厚度及余量，不把整条后方路径算进去。
- 只计入敌方存活地面部队、建筑和塔。空中单位、死亡单位、弹体、效果和明确非公开/不承受范围伤害的对象排除。
- 空地身份按实体的 `native_data_global_id` 查询已校验的实体形态表；该 ID 缺失时使用明确的 `evolution_state.current_form_id`。身份未确定时不当作地面目标。
- 不根据母卡判断空地：暗夜女巫的蝙蝠仍是空中目标，法术召唤的骷髅仍可作为地面目标。塔单独处理，保留滚塔收尾机会。
- 规则不预测未来轨迹，也不保证实际命中；目标可能在滚木到达前移动或死亡。这是压缩空放探索空间的策略约束。

## 接入与启用

`tools/event_rl_rollout.py` 和 `tools/demo_event_selfplay.py` 均支持：

```sh
--log-target-constraint --log-target-margin-tiles 0.5
```

同时启用闪电与滚木：

```sh
--lightning-target-constraint --lightning-target-margin-tiles 0.5 \
--log-target-constraint --log-target-margin-tiles 0.5
```

两个开关独立、默认均关闭。`--log-target-margin-tiles 0` 使用资源定义的扫掠区域。指定非默认余量但未开启约束会报错；录像入口的 `--no-mask` 与任一目标约束同时使用也会报错。

采样前按牌过滤落点，无落点时连带屏蔽该牌；全牌均不可选时只保留 WAIT。下发动作前再次检查最新观测，目标消失后取消计划、推进一步并重新决策，计入 `cancelled_log_target`。原采样动作、概率、经过时间和奖励保留在训练数据中。

规则保存在 shard contract 的 `action_constraints.log` 以及轨迹 `stats.json` 中，更新后的 checkpoint 通过 `rl_action_constraints` 留存训练来源。不同开关组合或不同余量的 shard 被 preflight 拒绝混合；旧的闪电规则标识和无约束模式保持兼容。加载权重不会自动开启约束，后续采集、评估须使用一致的参数。
