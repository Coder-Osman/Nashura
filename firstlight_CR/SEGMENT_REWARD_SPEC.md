# 分段势函数奖励训练规范（SEGMENT_REWARD_SPEC）

状态：草案 v1（待评审）
提出：用户方案（空场切分小局面 + 血量差分段奖励 + 价值网络修正）
范围：单倍圣水（1x）专精训练；验证后向双倍圣水（2x/3x）权重迁移

---

## 1. 背景与动机

作者的现有奖励 = 终局胜负 ±1 + 少量启发式整形。纯输赢信号在 6000 tick /
1200 决策的长视野下信用分配极慢，收敛困难。本方案将比赛按"场上无兵"
时刻切成小局面（segment），每个小局面独立结算血量差奖励，并用价值网络
修正起始状态的不对称（圣水差、手牌循环差），把稀疏的终局信号变成稠密
的分段信号。

## 2. 现状核实（代码锚定，2026-09-09）

作者并非纯输赢。`battle_env._rewards`（battle_env.py:4134）实际为：

```
reward = terminal_result(±1) + shaping_beta · (γ^Δt · Φ(after) − Φ(before))
Φ(owner, towers) = 皇冠差
                 + Σ_敌塔 血量损失比例 ×1 (王塔 ×3)
                 − Σ_己塔 血量损失比例 ×1 (王塔 ×3)
shaping_beta = 0.05, shaping_tau_ticks = 1200（PPO 环境配置）
```

另有 PPO 侧启发式：圣水溢出惩罚、猪部署奖励、首猪时机窗、火球激活王塔
惩罚（cluster_self_play.py）。

**结论**：本方案与作者的势函数整形同构（塔血差即势函数），差异在三点：
(1) 作者权重极弱（0.05），本方案将血量差作为 1x 阶段的主奖励；
(2) 作者逐 5-tick 施加并指数折扣，本方案按空场边界按块结算；
(3) 本方案显式引入分段边界上的价值网络自举项。

## 3. 方案定义（精确化）

### 3.1 分段（segmentation）

- 切分条件：**双方场上均无存活战斗单位**的 tick 区间。一局被切成
  S₀, S₁, …, Sₙ（含首段：开局双方空场）。
- 待定项 Q1（见 §5）：建筑/塔兵/投射物/生成物是否计入"有兵"。

### 3.2 段内奖励（第一近似：平费假设）

假设段首双方圣水相等、且本段未破塔，则：

```
r_seg(owner) = k · [ ΔHP_diff(owner) ]
ΔHP_diff = 本段内 (我方对敌塔造成的血量损失) − (敌对我塔造成的血量损失)
```

k 为缩放系数（默认 1/3000，即打掉一座满血公主塔 ≈ +1，与终局 ±1 同量纲）。

### 3.3 价值修正项（不平费/手牌不对称的推广）

移除平费假设后，段首状态不对称（圣水差、手牌循环位置差、已破塔差）。
引入状态价值函数 V̂(s)（预估该状态下后续期望净血量差收益）：

```
r_seg(owner) = k · ΔHP_diff + λ · [ γ^T · V̂(s_seg_end) − V̂(s_seg_start) ]
T = 段长 tick 数，γ = exp(−1/1200)（与 shaping_tau_ticks 一致）
```

**单位对齐**：V̂ 由 critic 回归同一奖励流得到，量纲自动等于奖励量纲
（k 缩放后的塔分）；r_seg 恰为合成势函数 Φ' = k·HP_diff + λ·V̂ 的段内
差分，两项可直接相加。γ^T 因子来自 V̂ 的折扣定义
（V̂(s_start) ≈ E[k·ΔHP + γ^T·V̂(s_end)]），缺失会引入系统性正偏。

- V̂ 复用 PPO critic 头（同一网络，观测已含双方圣水区间、手牌推断特征
  ——见 2026-09 新增的 public_in_hand_estimate 特性）。
- V̂ 取 detach（不回传梯度）；λ 冷启动 warmup：前 N 个更新 λ=0 线性
  升至 0.5（critic 早期噪声大）。
- 理论注记：r_seg 即 Ng et al. 势函数整形（Φ'）的分段聚合；
  固定 Φ' 时最优策略不变。V̂ 在线学习会破坏该保证（§8 风险）。
- 1x 截断设计的额外好处：奖励流无 ±1 胜负项，V̂ 目标是纯血量差预期，
  两项语义同源；进入完整对局（±1 恢复）后需重新标定 λ。

### 3.4 训练范围：单倍圣水

- 对局在 tick 2400（120 秒，2x 开始）处截断。
- 截断处的"终局"奖励 = 当前 Φ'（血量差势），不发 ±1。
- 全程保持 PPO 现有逐 5-tick shaping 通路（GAE 天然消化分段信号）；
  分段只是奖励记账粒度，不改变 MDP 结构。

### 3.5 验证后的迁移（2x/3x）

- 权重迁移：1x 模型作为 2x 阶段初始化，恢复完整对局（6000 tick）。
- 终局 ±1（按皇冠）恢复为主信号，分段血量差降回整形权重。
- 加入破塔（皇冠）显式奖励，王塔权重保持 ×3。

## 4. 理论定位

| 方案组件 | 等价/对应的成熟技术 | 新颖点 |
|---|---|---|
| 血量差分段奖励 | 势函数整形（Ng 1999）的段聚合 | 以空场边界聚合，权重为主信号 |
| V̂ 边界修正项 | TD 自举 / critic bootstrap（PPO-GAE 已含） | 显式按段结算边界差分 |
| 空场切分 | 局面分解 / options 边界（Semi-MDP） | 用领域先验找"近似状态重置点" |
| 1x 课程 → 2x 迁移 | 课程学习 + 微调 | — |

重要等价性：若 V̂ 即 PPO critic 且逐 5-tick 施加血量差，则
"r = ΔHP + λ(V'−V)" 与标准 GAE 数学上高度重合。因此实施必须包含
与"仅加大 shaping_beta 的朴素基线"的对照（§7），证明切分本身带来增益。

## 5. 开放问题（实施前必须回答）

- **Q1 空场定义**：建筑（Cannon 30s 存活、墓碑持续刷兵）计入吗？
  建议：仅统计战斗单位（troops），建筑与塔兵不计；若对手常驻建筑
  导致永不空场，退化为"双方 3 秒内无新增部署且场上单位 ≤1"的软边界。
- **Q2 永不空场的对局**：建筑流卡组可能整场无切分点。是否接受
  "单段对局"退化为纯势函数整形？
- **Q3 平费假设的残余误差**：空场瞬间常为防反方多费（防守效率高）；
  圣水 10 封顶泄漏不可观测（tracker 只能给区间）。依赖 V̂ 吸收，
  但需监控 V̂ 对圣水区间的敏感度。
- **Q4 王塔血量计入 HP_diff 吗**：建议计入但乘皇冠语义权重 ×3
  （对齐作者 Φ）；否则磨王塔血会与皇冠胜负错位。
- **Q5 被动性风险**：双方互不部署则每段奖励 0。血量差为主奖励时，
  是否需要保留作者的开圣水溢出惩罚（强烈建议保留）。
- **Q6 V̂ 的训练目标**：与 PPO critic 联合训练（TD on shaped return）
  还是定期冻结快照（防非平稳整形被利用）？建议：联合 + 小 λ +
  每 N 步评估行为统计。
- **Q7 段内 LSTM 隐状态**：段边界是否重置 recurrent 状态？
  建议 v1 不重置（保持标准 PPO 通路），段重置作为 v2 消融实验。
- **Q8 与镜像对局的交互**：镜像自对弈下双方策略相同，分段奖励
  零和（antisymmetric 已保证），确认无方差爆炸问题。

## 6. 实施映射（现有代码最小改动）

1. **v1（零新机制，1 天）**：
   - `ppo_environment_config_v4` 增配 `max_battle_ticks=2490`（1x 截断）
     与 `shaping_beta` 扫参（0.05 → 0.3/0.6/1.0）。
   - 截断终局奖励 = 截断时 Φ（复用 `_potential`，battle_env.py:4124；
     注意 terminal-zero-potential 约定已在 `_rewards` 注释中处理）。
   - 对照组：同配置不截断（全 6000 tick）。
2. **v2（分段结算，2-3 天）**：
   - BattleEnv 增加空场检测（双方 troops==0）与段边界记录；
     段内奖励聚合按 §3.2/3.3 写入 reward 通路（仍是逐 5-tick 发放的
     势函数差分，聚合只影响记账与日志）。
   - V̂ 修正项：critic value detach 加进 reward（λ 可配）。
   - 段边界重置消融（Q7）。
3. **v3（2x 迁移，验证后）**：恢复全程 + 皇冠主奖励 + 1x 权重初始化。

## 7. 实验与验收协议

- 主指标（1x 截断对局）：平均净血量差/局、段均血量差分布、
  首段（开局 0-30s）攻击性（部署数、圣水利用率）。
- 对照组：(a) 作者原配置；(b) 仅加大 shaping_beta（无切分）；
  (c) 本方案 v1；(d) 本方案 v2。
- 收敛判定：v2 在净血量差上显著优于 (a)(b)（≥2σ，100 局评估×3 种子），
  且无行为统计异常（被动率、溢出率、镜像胜率漂移）。
- 迁移验收（v3）：完整对局胜率 ≥ 1x-only 基线，且 2x 阶段行为
  正常（不再 1x 节奏打 2x）。

## 8. 风险与对策

| 风险 | 机制 | 对策 |
|---|---|---|
| 学习型 Φ' 失去策略不变性 | V̂ 在线更新被利用 | λ 小、V̂ detach、行为统计监控、可回滚 |
| 磨王塔血 vs 皇冠错位 | HP 信号与胜负条件不一致 | 王塔 ×3 权重、终局保留皇冠语义 |
| 被动均衡 | 双方空场收益 0 | 保留圣水溢出惩罚、评估攻击性指标 |
| 段切分永不触发 | 建筑流卡组 | 软边界定义（Q1/Q2） |
| 1x 过拟合节奏 | 2x 最优 ≠ 1x 最优 | v3 课程迁移 + 完整对局评估 |
| 血量差奖励黑客 | 纯法术磨血无推进 | 段内血量差含敌我双向（挨打会负）、
  溢出惩罚约束憋费 |

## 9. 与皮卡锤专精计划的关系

本方案先于专精训练验证（通用模型、任意卡组即可实验）；验证通过后
