# 闪电法术探索诊断（截至累计第 46 轮）

结论：模型与 PPO 架构支持学习闪电，但当前 RL 的观测趋势是降低闪电选择概率。样本证明策略仍有非零探索机会，不支持将问题归因于闪电被动作掩码永久禁用，也不支持假定仅延长训练即可学会有效使用。

## 学习路径与限制

- 卡牌 ID 28000007 在牌组与词表内；合法性由手牌、圣水、落点、可延迟交付等规则决定，无按闪电身份禁用。
- 动作为 gate → card → cell → delay 的分类随机采样，训练温度为 1；共享卡牌/空间表示允许泛化，所有当前策略参数参与 AdamW。
- PPO 对实际采样动作按优势更新卡牌、落点、延迟概率；未采到的闪电缺少直接的结果反馈，仍会受 softmax 竞争、共享参数和熵梯度影响。entropy coefficient=0.01 不保证每张牌得到最低探索比例。
- 现奖励主要为终局胜负及塔差，无“这一发闪电打中了几个关键单位、换取多少价值”的直接监督。昂贵法术若落点或时机初期较差，可能被降低选取概率，形成探索与收益不足的循环。这是待验证机制，不能仅凭频率下降认定。
- 当前石头人镜像对手可能给廉价单位循环提供更高收益；闪电减少也可能是在当前对手分布上的适应。另有石头人本体选择占 ACT 的比例从第 1–20 轮约 11.75% 降至第 41–46 轮约 3.85%，提示需检查整体打法变化，而非只盯一张牌。
- 总熵和自博弈胜率无法替代按卡牌的探索与使用质量指标。闪电空放、实际命中、圣水交换、塔伤贡献尚未逐次统计。

## 建议

1. 先补分卡牌日志：合法机会、条件概率、计划/实际执行/取消、落点、命中与伤害/击杀效果；用固定测试局面测高价值闪电和应当保留闪电的负例。
2. 若落点/时机基础薄弱，优先在当前 RL 检查点的实验副本上加入少量经核验的闪电示范，并混合原有牌/WAIT/负例，避免仅教“见闪电就放”；再接 RL。先保持原 12 小时运行作为对照，不直接修改运行中权重。
3. 如需要增加探索，可单独试卡牌温度小幅提高（例如 1.2），保持其他头温度。采样与 PPO 重评分必须同时采用并记录相同温度；若使用混合/定向探索策略，行为概率与 preflight 必须按真实行为分布实现，不能采样后强行替换卡牌却沿用原 log-prob。
4. 加入能够检验闪电价值的固定对手/局面，比较胜率、施法效率及其他能力是否退化。频率只是诊断，不以八张牌均匀使用或“施放一次加分”为训练目标。
5. 当前请求是能力与原因分析，本次未改变训练超参、奖励、权重或停止 12 小时训练。
