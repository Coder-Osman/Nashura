# RL 扩大评估与下一阶段训练建议

证据日期：2026-09-18。训练已完成至第 171 轮。本轮只执行冻结权重评估和审计；下述训练实验与模型改造尚未启动。

用户明确的架构偏好（本轮补充，长期适用）：上一动作特征有意设为空，希望策略依据当前局面推断，不引入跨决策神经记忆。以下建议按此约束调整；空上一动作不是待修缺陷。当前工具未提供 create_memory，偏好在此文档落盘。

后续参数审计：正式模型仍为 13,046,380 参数；去除旧解码器、重置 LSTM 无效项，并折叠空上一动作分支后，内存候选为 8,551,683 参数。94 条真实样本的输出数值等价检查通过，尚未替换正式模型。这是保留原函数的实现精简，与改成新残差 MLP 的架构实验不同。详见 [参数审计](evaluations/parameter-audit-20260918/report.md)。

## 扩大评估

第 171 轮对第 140 轮，新增固定 2,160 局：1,080 个全新种子，每个种子交换双方位置。全部采用石头人镜像、11 级、四头采样温度 1、胜负奖励 margin beta=0、最大推进 30 tick。先固定样本量，跑满后判断。

最终结果见 [扩大评估报告](evaluations/expanded-171-vs-140-step30-20260918/report.md)。以新增批次作为主要证据；与旧 432 局合并的 2,592 局仅作辅助。旧批次的 53.70% 胜率（配对 95% 区间 49.07%–58.33%）促成了扩样，故不只凭合并区间宣布提升。

**扩大结果：第 171 轮 1,192 胜 / 0 平 / 968 负，胜率 55.19%，配对 95% 区间 53.24%–57.13%；位置 0 / 1 胜率分别为 55.37% / 55.00%。全部 2,160 局完成，worker 重试 0 次。独立新增样本支持 171 强于 140，尚无证据判定训练已经停滞，更没有据此诊断架构容量瓶颈的理由。** 后续实验目标是提高进步效率，现配置继续作为有效对照；保持用户选择的无跨决策神经记忆方案。

此前同为 30 tick 的评估中，171 对 60 / 70 / 100 轮分别为 66.67% / 60.88% / 57.41%，区间下界均高于 50%。这些结果证明相对早期版本有进步；仅凭相邻版本的小优势或区间重叠，尚不足以诊断模型容量瓶颈。镜像内部排名也不代表真人或跨牌组水平。

## 先做训练方式实验

### 0. 先处理采集可靠性并补诊断

续训前将采集和评估统一到验证过的最大推进 30 tick，并对 phase ring 容量/消费时机查根因。30 tick 是已验证缓解措施，尚不等于根因修复。失败保留原 checkpoint、种子、温度与日志，按原场景重试；持续失败则让整轮明确失败，避免换种子筛掉复杂场景。对已知失败种子做回归，并验证推进步长改变是否影响模型收到的决策事件。

补充每头 KL、合法支持归一化熵、actor/value/entropy 梯度范数及方向、value 的 held-out explained variance/校准、时间间隔分布、真实执行回执。非法动作计数为零仅证明合法性，不证明策略质量。

第 171 轮全部 4,066 条记录的 `previous_action.action_mask` 均为空，`micro_action_count` 和 gate 均为 0，符合用户主动选择的无记忆设计。此前将它列为需要补齐的方向，现撤回；保留空特征，仅在未来数据契约检查中验证 IL、rollout、评估和训练重算遵循相同输入约定。本地 IL producer 的更新函数存在，不足以证明最终 IL 输入不一致。

### 1. 第一优先：1 epoch 对 2 epochs

从同一第 171 轮权重和 AdamW 状态分别启动 A/B，先固定各 30 轮，每轮 108 局、216 条 learner 轨迹；A 仍为全批 1 epoch，B 仅改全批 2 epochs。lr=1e-5、奖励、熵系数、对手和其余参数固定；两组都使用相同的可靠采集实现。记录等采样预算下的实力和各自总耗时。30 轮适合作为探索预算，若差异未确认，不把它视为等效证明。

现实现有每个 optimizer step 后、对完整 rollout 的 KL 检查；越过阈值的那一步会保留，仅阻止后续步骤，所以它不是硬 KL 上界。增加 epochs 前应有非有限值拒收、过大偏移的权重与优化器回退策略。继续沿用 0.01 为停止参考；先观察实测 KL 和胜率，不同时加大学习率，不直接跳到每条轨迹一个 optimizer step。若 2 epochs 有稳定收益，再单独试 4 epochs。

探索评估可每 10 轮对固定 100 / 140 / 171 及独立参考策略各跑 108 对换边局，用于筛选和发现退化。选定候选后，再对候选与 A 组终点预先固定 1,080 对全新换边种子，作为主要确认比较。升级要求主要比较配对区间下界高于 50%，并核对旧对手上没有明显回退；对“不退化”的正式声明需预设容忍边界并作相应区间检验。多个候选筛选后应另留确认种子，不把逐轮最好的一次当最终证据。额外训练随机种子复现实验用于衡量训练方差。

### 2. 出现循环克制或遗忘：混入历史对手

先试 80% 当前镜像自博弈、20% 历史冻结对手；历史部分在 100 / 140 / 171 及近期版本中均匀抽取，比例只是实验起点。维护固定对战矩阵，观察是否只会打自己、赢新输旧、或发生循环克制，再考虑按难度抽样和更完整的 league。

现有冻结对手接口只让 learner 位于 owner 0，仅收它的轨迹。加入对手池时需同时支持 learner 位于两侧、对称采样并仅收 learner 轨迹，冻结对手的动作不能当成 on-policy 数据。镜像一局提供两条 learner 轨迹，历史对手一局只提供一条，因此对比需报告有效 learner 决策数与总算力；相同局数并不意味着相同训练数据量。

### 3. 时机失误明显：先改信用分配，再考虑改动作头

第 171 轮 108 个 shard 共 4,066 条决策：实际间隔中位数 107 tick，均值 138.22，90 分位 300，最大 1,141。以项目 20 tick/s 换算，中位数约 5.35 秒、最长约 57.05 秒，明显不是等时距决策。

先明确目标：若目标就是终局胜率，不希望偏好快速胜利，可独立测试 gamma=1，并单独选择 GAE trace 的衰减尺度；若希望按真实时间折扣，使用 `d_t=exp(-delta_ticks/tau)`，`delta_t=r_t+d_t*(1-done)*V_next-V_t`。trace 衰减也应明确是按决策还是按时间；时间版可用独立的 `l_t=exp(-delta_ticks/tau_trace)`，递推系数为 `d_t*l_t`。终局奖励发生在区间末端时，应明确区间内奖励折扣约定，使 value warmup、MC target 和 GAE 一致。

已有 `EventPolicyConfigV1.discount` 的默认 tau=1200 tick，但目前 GAE 未调用；不能直接接上这个默认值而声称只是修复。138 tick 时它约为 0.891，而现在每步为 0.999，会显著改变有效视野。应根据真实间隔分布与目标回报选择尺度、单变量对照，并同步训练配置/数据契约和测试。公开 GAE 文献支持其偏差—方差权衡；具体时间尺度需本任务实测。

### 4. 按动作头处理探索与 critic

第 171 轮在“确实有多个合法选择”的状态上，平均 `H/log(N_legal)` 如下；card/cell/delay 仅统计 ACT 样本，并条件于已采样的上游动作：

| 头 | 归一化熵 |
|---|---:|
| WAIT/ACT | 0.060 |
| 选牌 | 0.446 |
| 落点 | 0.715 |
| 延迟 | 0.842 |

WAIT/ACT 均合法时 99.10% 选择 ACT；ACT 可预约未来 0–6 秒出牌，故这不等于 99.10% 的状态立即出牌，也不单独证明失误。应比较胜负局、卡牌、圣水量和推线阶段，核查已执行落点、法术空放、费用溢出、过度防守、预约后错失响应等。现有统计主要是合法性与提交计数，未直接验证这些战术问题。

若失败样本集中在落点/延迟随机性，单独试相关熵系数从 0.01 降到 0.005，或定义按合法支持归一化的分头正则；二者是不同目标，不同时改。保留必要探索，并用真实对局判断。若 critic held-out 预测仍差，先试独立 value 尾部或额外 value-only 更新；当前已存在独立 value 层，共享骨干也会影响 actor，不能把更新共享参数称为完全冻结策略。

## 什么情况下改架构

**LSTM 不是 PPO 或对战 RL 的必要组件；按用户目标，优先保持只依赖当前输入的前馈策略。** 目前每个决策将 hidden/cell 置零，LSTM 只是带门控的非线性变换。简化地说，`c=i(x)*g(x)`、`h=o(x)*tanh(c)`；过去的 hidden/cell 不进入当前预测。零状态下 hidden-to-hidden 矩阵不贡献本次输出，forget gate 对零 cell 也不起记忆作用。因此“代码有 LSTM”不代表策略有记忆，也不说明需要时序训练。

无记忆也不等于短视：策略只读取当前输入，GAE 和终局奖励仍沿整条轨迹分配信用，训练当前动作对未来胜负的价值。网络是否保存历史，与训练目标是否考虑长期收益，是两个独立问题。

当前快照包含单位位置、血量、目标、攻击阶段/冷却、投射物等动态语义，远比一张静态截图丰富。局面推断可以学到“此刻应防守还是进攻”，无需先引入 RNN。现输入还含公开牌序距离、手牌/下张牌估计、敌方圣水上界与不确定性：这些是观测构建器保存的历史摘要，模型本身仍可无状态。若目标进一步要求整个系统完全不使用历史，需另行评估这些 tracker 特征；本次保留现有约定，不自动删除。

用户进一步明确关心仅使用公开可推算信息的对手圣水和手牌。已核对实际训练快照（tensorizer、tracking、battle_env 均与本地源文件 hash 一致）和第 171 轮全量 4,066 条输入：对手精确 `in_hand` / `is_next_card` 均为 0；2,841 条有 `public_in_hand_estimate`，3,059 条有 `public_next_draw_estimate`。对手牌 token 仅包含已公开卡和未知卡占比；初始未知手牌不伪造为已知。圣水输入为上界与区间宽度，本批上界约 0.179–10 费；tracker 当前保守地将敌方下界置为 0，以涵盖未观察到的能力消耗等。例如 tick=982 的一帧编码区间约为 [0, 2.695]。FAIR 观测把对手精确圣水置空、手牌置为空元组，私有状态校正仅作用于当前观察者。此设计允许外部公开信息追踪与无神经记忆策略并存。进一步改进方向可包括在事件覆盖充分的规则/卡组下收紧圣水区间，并显式保留不确定性；是否能够收紧须以公开事件完整性为依据。

无记忆策略的真实限制是信息混叠：同一个当前可见局面可能对应不同隐藏手牌/圣水，最佳动作也不同。模型可以学条件分布和稳健策略，但当前输入中不存在的信息，单靠加宽网络也不能精确还原。若已有快照和合法公开估计足够支持高质量决策，记忆带来的增益可能很小；仅凭理论上的部分可观测性不足以推翻当前设计。

无记忆架构的优先对照：保留实体 Transformer、空间编码器和四个动作头，将重置式 512 维 LSTM 换成 2 层残差 MLP（或门控 MLP），输出维度保持 512。对比现有重置式 LSTM 与 MLP 的实力、吞吐和参数量；不要直接删除 LSTM 后套用旧权重，需从旧策略蒸馏/IL 适配或重新训练对应模块，并更新 checkpoint 契约。它可能简化实现、节省部分计算，但主干开销与实际吞吐需测量，不承诺必然更强。现有权重已有实力，先保留作为基线完成训练效率实验。

若误差集中在卡牌与落点、时机的联合选择，可针对相关头加入目标实体/区域表示，或探索有限候选联合评分；当前已经有 card-conditioned cell、card/cell-conditioned delay，先检查条件表示是否足够。动作表示变化会改变 IL 标签、合法性和采样分布，也要作为独立实验。

只有在训练方式、历史对手、时间处理和观测诊断后，仍显示 held-out 策略/价值预测欠拟合且加宽有稳定收益，才试更宽或更深的前馈骨干。比较时同时报告每秒对局、有效决策吞吐和等墙钟实力；五机 CPU 采集可能因模型变大而显著变慢。13M 参数本身既不能证明充足，也不能证明不足。

如果目标转向多牌组或真人水平，应先增加独立对手和跨牌组测试，再引入混合牌组课程。当前镜像内部胜率不能支持泛化结论。

## 建议执行顺序

1. 采集可靠性与分头/critic 诊断。
2. 同 171 起点的 1 对 2 epochs 小规模 A/B；确认有收益再延长。
3. 若出现遗忘/循环克制，增加 20% 历史对手。
4. 由时机与战术诊断决定时间折扣、分头探索实验。
5. 需要架构实验时，先对比重置式 LSTM 与无状态残差 MLP，再根据欠拟合证据调整前馈容量；跨决策记忆不属于当前方案。
