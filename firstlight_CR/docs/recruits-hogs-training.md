# 五卡组持续混合训练

新增策略 `five-deck-recruits-hogs.v1`，沿用 `mixed-deck.v1` 对战记录格式。第五套训练卡组为 `recruits-hogs`（卫队猪）：

| 卡牌 | 原生 ID |
|---|---:|
| 皇家卫队 | 26000047 |
| 皇家野猪 | 26000059 |
| 飞行器 | 26000057 |
| 电击车小队 | 26000052 |
| 哥布林牢笼 | 27000012 |
| 火球 | 28000000 |
| 万箭齐发 | 28000001 |
| 野蛮人滚桶 | 28000015 |

全部基础形态、等级 11、公主塔；沿用当前调度、执行确认过滤、温度及动作约束。

每轮仍为 108 局：72 局自博弈，12 局固定历史对手，24 局近期历史对手。固定池仍为 B0、600、645，近期池仍为至少落后当前模型十次更新的两份完整混合训练 checkpoint。历史对局只训练当前模型的一方。

五套卡组组成 25 个有序对战组合。每组合三局，其中每轮轮转选出的三个镜像组合减为两局，合计 72 局。历史对战仍由 18 组交换上下方的同种子配对组成；三个减少镜像的卡组各分配四组历史配对，另外两套各三组。这样每套卡组恰有 36 条预期训练轨迹，上下方各 18 条。无有效决策的轨迹仍按既有规则排除。

PPO 各卡组有效决策独立平均，各占 20% 学习权重。石头人 B0 reference KL 控制器、AdamW 状态、绝对训练轮数、学习率和其余 PPO 参数连续保留。

`deck_policy` 纳入冻结计划 SHA、采集元数据和 checkpoint 元数据。重试复用已冻结计划，错误策略、牌序、归属、轮次和不完整卡组样本均拒绝更新。旧计划缺省 `deck_policy` 时严格保留原四卡组分配与 SHA，原四卡组评估沿用历史冻结运行时。

运行模式为 `continuous`，轮数与时间上限为 null，定期独立评估关闭。磁盘、回执、身份和训练异常保护继续生效。通过 `STOP` 在完整轮次边界停止，不清理用户视频、训练权重或历史资料。

部署采用五台机器各自的 `recruits-hogs-v1-code` 独立冻结目录及同一 `recruits-hogs-v1-manifest.json`；活动目录不原地修改。远端审计位于 run 下 `recruits-hogs-20260920-audit/`，本地审计位于 `artifacts/recruits-hogs-20260920/`。正式生效轮次及真实验收见该目录的验收报告。
