# 只训练有效决策

学习契约：`executed-act-or-wait.v1`。调度版本仍为 `event-scheduling.v3`。

`EventLaneRecorderV1` 保存所有原始决策。ACT 采样后处于待执行状态；提交引擎时绑定唯一 `action_id`，只有收到同一动作的原生 `action_executed` 回执后才可训练。队列接收回执不等于执行成功。回执先于终局关闭处理；迟到回执按原动作标识更新原始记录，既不丢失已执行动作，也不把确认误记到替代决策。

| 原始决策状态 | 是否参与训练 |
| --- | --- |
| 正常 WAIT | 是 |
| ACT，原生回执确认执行 | 是 |
| ACT，被新事件决策替换 | 否 |
| ACT，执行前手牌、窗口、坐标或法术目标失效 | 否 |
| ACT，引擎拒绝或终局取消 | 否 |
| ACT，仅提交但没有执行确认 | 否 |
| 历史样本，没有执行状态 | 拒绝用于训练，需重新采集 |

训练入口先检查完整原始轨迹、行为权重身份和原有契约，再只用有效决策组装训练 lane。原始 ACT、delay、概率、观察和取消原因保留在 shard 中，不把取消的 ACT 改写成 WAIT。

被排除决策的观察、动作和概率在进入模型编码前就已移除，因此不会进入价值函数预热、GAE 的价值估计、优势归一化、PPO、熵、KL、辅助模仿损失或优化器批次权重。合批缓存与普通路径共用这一入口。

相邻有效决策间的被排除记录，其时长和奖励并入前一条有效转移。特别是终局发生在未执行 ACT 的等待期间时，真实终局奖励和 done 标记仍传给上一条有效决策。第一条有效决策之前的记录只保留作核对；整个 lane 都没有有效决策时跳过该 lane，整个更新都没有有效决策时在创建优化器之前报错。

`decision_ticks` 保存合并后的实际时长。gamma/lambda 延续原有的按决策折扣规则，决策现在指有效决策；没有切换为按真实 tick 折扣。历史已训练权重及优化器中的影响不追溯撤销。

摘要及训练日志报告原始行数、有效行数、排除行数、空 lane 数和执行状态分布；新 checkpoint 保存 `rl_execution_credit_contract` 和 `rl_execution_counts`。切换运行时必须从完整轮次权重恢复，并重新采集下一轮，禁止混用旧 shard。

回归测试覆盖 3 秒事件替换 5 秒计划、双方视角、替代 ACT/WAIT、延迟观察、终局回执、迟到回执、未确认提交、全排除 lane、历史数据、终局奖励和时长保留。参数对照测试同时启用 PPO、价值、熵、KL、BC 及价值预热，验证任意破坏被取消样本的动作和概率仍不改变最终参数。
