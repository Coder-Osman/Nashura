## 修改

- 每 tick 直接增量收集正常执行收据，保留相同可见性过滤、位置、排序和去重，避免额外生成双方观测；仍逐 tick 推进。
- 在 native 重放前用采样牌序模拟对手已公开出牌的手牌/循环队列，提前拒绝必然缺牌的样本。无新 RNG 消耗、无额外重采样、无预算调整，接受世界的采样分布保持相同。
- 每个信念世界捕获完整 `BattleEnvSidecar`；每次模拟恢复事件环、队列、HP 差分基准、执行收据、缓存及相关 Python 状态，再恢复 rollout 和允许的信息历史。
- native 快照恢复开启新的日志代次，但日志序号为进程级递增；在一致的恢复 tick/代次与完整、无溢出、无拒绝的日志边界上重绑定游标。combat、visibility、remaining 要求空日志；phase 只允许恢复观测产生的根 tick `movement_scale` 测量记录，并验证序号连续。其他事件和未来 tick 仍拒绝，常规消费中的丢事件检查不变。
- 临时重放 `step` 包装在结束后恢复原来的实例字段状态，避免将绑定方法及 transport 锁纳入环境快照。
- 新 runtime 身份包含 PUCT、FAIR native 与 belief 源码哈希。
