# Codex 回执：初始化参数来源

- `RUNTIME_OBSERVED_LIMITED`：Android 数据库初始化位于已构造对象的初始化作用域内；第二参数匹配上游持有者字段。
- `UNIT_PASS`：身份绑定审计 exit 0；完整相关测试 1083 passed、1 skipped。
- `BLOCKED`：持有者字段的类型与构造、配置异常和 Backup 等价；严格 catalog 门未通过。
- `NOT_RUN`：Linux 该初始化入口、ResourceManager、GameState、Step 和完整对局。
