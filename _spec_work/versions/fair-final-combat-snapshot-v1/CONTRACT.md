# 有战斗轨迹的快照续演：限定原生验收

本实验补充global-rng-snapshot-v1的WAIT证据，不改旧构建、Full128或迁移部署。
固定相同libg、已验收的单通道全局MT引擎及343文件运行时，两个独立新进程。
比赛seed为78101981，执行流seed为78101991；固定速猪、11级、基础形态、公主塔。
不使用模型或搜索，不产出训练数据，不宣称教师强度或G0/G1闭合。

双方动作仅依据各自先冻结的FAIR合法掩码。使用固定卡牌/目标优先级，延迟按
tick奇偶选择1或30，不看后续收益；双方先选完再统一提交。正常取消保留；
协议失败、拒绝、截断或提前终局保留失败现场，不跳过或更换种子。

推进到tick110/600/1200，各保存一次完整rollout快照，连续执行两条各60tick
分支。每个tick比较native+全局MT摘要、原生摘要、公开实体/塔血量、预约时钟、
双方FAIR语义摘要、执行RNG及结算记录。每条分支之后恢复原根，核对完整根身份；
释放所有句柄。全局MT仅只读采样，不扰动，不将未观察到写入当作不可达证明。
阶段证据必须包含双方合法ACT执行、非塔实体及公开血量损失，排除空WAIT轨迹。

每个进程探针上限300秒，worker沿用360秒及所属引擎清理；29783专属端口。
启动前至少32GiB可用内存、5GiB磁盘，中心200GiB及两代容量门保持原义。
launch事前绑定父验收、构建、源码、配置和本契约；完整归档由外部固定SHA验收。
原始帧、合法掩码、全局字节、引擎保持私有。公开实现及摘要。

该证据不是完整搜索对局、一般pending/fallback信念验收或全部随机消费者覆盖。
training_admissible、hidden_random_coverage_closed及gates_closed始终false。
