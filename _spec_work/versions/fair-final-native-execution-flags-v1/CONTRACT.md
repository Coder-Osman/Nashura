# ct86 保存参数的局部寿命审计

2026-10-23，在原生 mode 审计已观察到 bit0-set 后，进一步核对队列调用参数。
独立工具只读固定 SHA 的 libg；不修改冻结运行时、游戏二进制或后台 Full128。

复用并逐字节绑定 command/queue 审计器，核对 vtable、两处队列调用与执行器。
对 ct86 入口保存的 w2 参数做保守控制流遍历：捕获到 w23 后，直到恢复调用者
x23 或用新结果覆盖 w23 为止，所有显式读取必须是已登记的两个 bit1 测试。
额外别名读取、未分类写入、过早返回、路径缺失和越界控制流均拒收。

固定二进制中：

- age20 路径传 w2=2、w3=0；bit0-set 路径传 w2=3、w3=0。
- 保存参数的显式读取位于 0xd30c68、0xd30d98，只检测 bit1；2 和 3 在该位均为1。
- bit0-set 类型3路径包含命令 tick 与当前 tick 的相等检查；不是 age20 的延迟路径。
- 0xd30e0c 调用 0xf3816c 后仍按结果分支；其他校验错误也仍在局部控制流中。

因此不得只因为参数 3 比 2 多一个 bit0，就认定它跳过了所有校验。
也不得反向声称两条队列或整个执行器等价：队列前驱、时序与副作用不同；
原 w2 或别名仍可能进入不透明 helper，本工具未证明 helper 参数独立性。
跨调用追踪 x23 明确依赖被调用方遵守 callee-saved 约定，不把该假设当动态证据。
不赋予错误码未经证实的语义，不证明合法拒绝可达或全局不可达，不证明 mask 等价。

test_flags.py 的合成指令对象只验证分析器的拒收边界；私有库存在时另运行真实
固定二进制分析。公开环境缺少该库时跳过该项，不制造原生执行证据。
static-report.json 为固定二进制静态结果；provisional/ 保留首次分析的原始草稿，
草稿关于等价性的表述已收窄，以正式报告为准。所有结果均非训练准入或整体验收。

```sh
python audit_flags.py PATH_TO_FROZEN_LIBG --output static-report.json
python -m pytest -q test_flags.py
```
