# 延迟补牌先验：独立只读审计

## 目的与边界

继续闭合冻结TRAINING_SPEC §1/§2及G0/G1的原生补牌支持证据。旧诊断的
三局1044帧包含20个支持缺失，全部位于三张手牌的补牌间隔。原因是旧离线
PublicCycleBelief诊断使用即时轮转，而原生可用手牌与next遵守延迟补牌。
本版本仅更正离线审计的状态表示和时间推进，不改线上搜索、冻结部署或先验。

DelayedCycleAudit仅接收冻结卡组频次、公开执行牌及公开tick；四个手牌槽位
保留-1空槽，FIFO随待补牌增长，按既有20/10/7 tick相位推进补牌时钟。
同tick执行与补牌的先后顺序对齐既有ConditionalDraws，不根据私有标签调整。
手牌/next真值仅供评分，支持要求精确手牌集合、空槽数和next联合相容。
失败增量不提交支持集或时钟。计数加权、不引入收益或隐藏世界身份。

复用既有不可变先验、数据来源验收与整局等权统计，避免重复实现这些契约。
不将本模块作为搜索世界采样器，也不声称其包含隐藏预约或完整策略似然。

## 原生与数据核验

run_audit.py首先重验三局原生完整数据来源和旧诊断数据/代码SHA，再验既有
原生完整补牌轨迹。轨迹146个变化时刻、两玩家共292个状态：用公开执行历史
推进，并逐项对照手牌槽位、FIFO、空槽和补牌时机。此处额外使用已知原生
开局顺序作为验证参考，绝不用于三局先验预测。292个状态全部精确一致。

三局的预测仍从所有40320个初始排列开始，不使用参考开局牌序。所有1044帧
重新评分、零排除；每帧评分前后核对支持摘要，私有标签没有改变预测状态。
按整局等权next Brier为0.047203284804426794，支持覆盖1.0，零next概率率0，
联合兼容质量0.9467529013806049。原即时补牌诊断Brier约0.084558、支持
覆盖约0.980948。差异来自状态语义修正，不是学习带来的预测提升。

最终attempt：native-exact-audit-20261022，plan/report/private-audit/native-timing
和运行源码副本均保留。较早native-audit-20261022及失败测试报告继续保留。
独立verify_audit.py重新推进全部1044帧、重算每个分组和可靠性统计，并检查
数据不漏不重、源码与归档身份、原生精确参考和训练准入限制。
verification.json为passed_limited_diagnostic，training_admissible=false、gates_closed=false。

## 测试与限制

恢复、无效更新原子性、私有标签非干扰、精确手牌与空槽、频次权重，以及
真实证据正例和8类篡改拒收。它与先前确定性运行的另一组19项分别统计。

类型转换后完整重跑通过，原报告没有改写；原生审计数值不受该修正影响。
