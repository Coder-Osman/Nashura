# 原生位置拒绝条件的条件化语义核验

本项直接读取固定SHA的libg.so中位置校验函数0xcfcf50..0xcfd094及其
ct86调用点，不改动游戏、冻结部署或正在运行的Full128任务。

以独立Unicorn 2.1.4 AArch64 CPU执行全部81条原始指令，与单独的参考
公式对照。六个直接调用及一个虚调用的函数体不在本项证明范围；将其
结果显式作为输入或无语义的通知，检查调用参数并破坏caller-saved寄存器
和NZCV，以免误依赖被调用者保存临时值。所有样例使用合成结构体内存，
不是完整原生游戏对局，不证明这些结构体组合在速猪游戏中实际可达。

局部返回公式（有符号32位，减法按32位回绕）：

1. 卡牌辅助查询返回空：0。
2. x < -499：1。
3. trunc(y / 500) < lower_y：2。
4. trunc(x / 500) >= upper_x：3。
5. trunc(y / 500) >= wrap32(upper_y - lower_y)：4。
6. 地形辅助返回值的最低位为0：5；否则0。

notify仅影响失败时是否发出通知，不改变返回码。这里的500是原生内部
分区尺度；Python动作网格使用1000世界单位，不将二者直接解释为冲突。
不凭空给结构体字段加上“领地”“塔碰撞”等尚未证明的游戏语义。

乘法除500还以整数界证明覆盖全部有符号32位输入：
M=274877907，S=2^37，500M=S+28。
对|n|=500q+r，q<=floor(2^31/500)，0<=r<=499，有
0<=28q+Mr<S，且|n|>0时该余项严格大于0。结合负数向下取整后的
符号修正，得到原指令等于向零截断除500；乘积也落在有符号64位范围。
这份整数证书只证明算术恒等式；CPU差分样例不是2^32穷举。

ct86以0作为继续执行，其他返回值加14，因此本地位置拒绝码为15..19。
本项不证明其余ct86拒绝条件、地形辅助本身、live queue全调用路径、
合法mask在预约到期时的充分性、一般pending可达性或随机机制覆盖。
G0/G1及training_admissible保持未通过。

## 重现

将unicorn==2.1.4安装到独立目录，设置PYTHONPATH指向该目录；不需要
更改项目环境或任何运行中的引擎。审计还需要已有capstone和lief。

```sh
python run_audit.py /path/to/frozen/libg.so --output /path/to/report.json
python -m pytest -q test_position_guards.py
```

报告记录库、函数片段、调用点、源文件及依赖版本，确定性样例摘要、
返回码和指令覆盖。检查失败立即退出，保留原报告；输出文件独占创建。
