# 虚分派调用点的独立动态审计

本版本保留 live-command-v1 的冻结实现与归档。插件采用显式
`FairFinalPluginEntries/v4`，每条记录按顺序保存指令地址、采样PC、
X0、X1、X30、X8；X8使用独立字段，不复用X1含义。仅支持就绪后ARM。

增加0xd2f838的`blr x8`和0xd2f83c的返回后指令，连同原15个点共17点。
固定库SHA和0xd2f820至0xd2f83c的指令字节共同核验虚表加载及调用方式。
在同一vCPU逐调用核对X8目标、ct86入口、对象X0、实参X1、LR及W0返回。
其它目标记录配对调用与返回，不据此解释其完整语义。

原生实验复用父协议的三独立进程完整对局、观察边界、正向对照、
所属引擎清理及监督封存验收；独立验收重新读取原始日志。运行时源代码
变换必须精确匹配父形状，源SHA登记在launch和下载回执中。

该证据只涉及实测轨迹，不证明逐预约对象映射、一般合法拒绝可达性、
全部动作mask充分性或其它随机算法覆盖；G0/G1及正式阶段准入保持独立。
