# 预约动作坐标与原生读取字段

继承reservation-map-v1的逐预约对象关联，独立v5插件只新增X2读取；既有X1为
位置helper的横坐标，X2为纵坐标。固定库指令核验执行器从命令对象+0x28加载
W1/W2，直到调用位置helper没有覆盖；helper入口前采集寄存器，按执行器对象
关联预约，支持同tick双方执行顺序变化及跨tick对象复用。

独立公式从18×32模型格点、玩家旋转、执行时placement偏移、舍入及边界裁剪
重算世界坐标，先比较HandAction，再比较原生执行器实际加载的W1/W2。偏移
元数据在排队前单独采集；不将此声明为完整mask合法性或偏移来源等价证明。

继承三独立进程完整合法轨迹对比、原生终局、日志封存、逐预约结算及所属清理
验收。旧v4归档没有X2，明确拒收。真实字段未采集时仅报告工程测试通过。

结论限定本轨迹的坐标转换与原生加载字段；原生内部卡牌字段、一般合法拒绝、
完整mask、其它随机机制、G0/G1总门及模型强度仍单独验收。不修改冻结部署。
