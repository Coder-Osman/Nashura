双方反向执行和对象跨tick复用；缺X2的旧v4完整成功归档明确拒收。

## 工程验证

初次38项通过1.53秒。补入parser和冻结运行时对照后的review为39通过/1失败，
原因是测试引用了不存在的NativeBattleEnv类；该失败报告原字节保留。修正为
BattleEnvV1，并把整个运行时对照放进独立进程，强制核对实际导入的冻结路径，
避免已加载的主工程模块冒充冻结版本。

隔离复核40项通过/1项待私有归档跳过（5.31秒）；其中2×576×3=3,456种
玩家/格点/偏移组合与冻结实际转换一致，v5原始行parser保留X1/X2/X8字段，
拒收旧版本、缺字段和坏编码。测试集合重叠，不累计。工程fixture不代替原生局。
