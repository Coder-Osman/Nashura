# 原生动作执行链：实测及验收边界

## 工程检查

本版独立扩展七个动作执行指令点，保留父版本八个随机入口。固定库SHA与七处
原始指令字节逐一核对；插件只读PC/X0/X1/X30，不修改游戏内存、guest参数或
原生alarm。父完整终局/三组轨迹/清理验收保持，新增执行器与helper配对核验。

tests-prearm-native.xml：28项通过、1项因当时第三次完整归档尚未产生而跳过，0.92秒。
包括两次真实失败归档独立拒收、指令身份、生成字节、源码形状、ARM前过滤、
调用边界与返回值破坏拒收。工程测试不代替三组原生完整轨迹。

仅有日志头既不证明动作执行器未调用，也不证明一般拒绝分支不可达。

## 整体边界

本专项即使通过，也仅证明绑定库、有限脚本和十五指令点上的实际调用链。
不证明虚分派调用点、全部合法mask充分性、一般pending/拒绝可达性或全随机覆盖。
Full128完整终局、terminal选优、round2原生及其它G0/G1缺口分别验收。
G0/G1开放，限定登记34/43不变，G2–G8和正式训练未运行，training_admissible=false。
原始地址/寄存器、私有审计、权重和第三方库不发布。
