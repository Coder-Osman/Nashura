# 预约到原生命令对象映射实施记录

## 工程验证与范围

独立版本继承dispatch-command-v1的17点v4插件，部署源码仅替换plugin_probe.py；
保留父插件、运行时、库及两个后台冻结任务。为每次原生同步入队记录独立日志
字节范围和预约身份，按唯一构造对象匹配同tick的ct86执行入口；双方反向执行
亦以真实对象归属，跨tick对象复用允许，同tick重复对象拒收。

独立验收从完整决策记录重建预约，与最终结算身份、动作、due tick及执行回执
对应，核对构造/执行日志全覆盖，并继续运行父归档、完整三组对照及清理验收。
回执身份不是原生命令内存字段的证明；坐标转换及对象内部坐标字段本次未独立
重算。一般合法拒绝、完整mask和全部随机机制仍另行验收。

初次27项工程测试通过；补入跨tick复用、日志切割和归档边界后，32项通过、
1项因本次原生归档尚未生成而跳过（0.74秒）。审查后的31项纯工程测试通过
（0.70秒）。测试集合重叠，不相加；真实父dispatch完整成功归档缺少逐次入队
区间时被实际验收器拒收。初始报告保留，不将工程fixture记作原生结论。
