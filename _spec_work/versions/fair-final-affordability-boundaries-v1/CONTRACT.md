# 最早合法延迟的原生诊断

旧合法预约探针只选择延迟1和30；已有四根合法mask包含最早延迟2、4、15、18、25。
本实验仅从公开合法mask按卡牌、位置寻找最早合法delay>1，按同一阈值的位置
取首尾两格，并测试该阈值与下一档。另一玩家WAIT；双方观察先冻结再统一提交。
阈值由完整mask定义，不把阈值变化未经核实地全归因于圣水。

复用冻结history-v2和旧预约诊断的实际规则、完整边界与双次快照续演检查；
不绕过合法mask、不修改实际手牌、资源或命令结果。使用已独立验收的global-MT
快照引擎，单独29803端口、一个原生引擎，内部1200秒、worker1260秒上限。
启动前绑定全部载荷和父引擎凭据；停止后下载并固定回执，再独立复核。

没有延迟阈值的根登记双方WAIT基线；验收仍要求四根覆盖及非空阈值试验。
必须逐根从保存mask重算完整登记候选，与试验顺序和动作逐项相等。
复用旧验收器的合法性、原生执行、时钟、抢占、恢复与清理检查。
这是单轨迹有限位置诊断；即使零拒绝，也不证明全局不可达。
发现拒绝后仍需另验独立信念重建、Full128与恢复。
所有准入门保持false，运行中的Full128和选优任务保持原样。
