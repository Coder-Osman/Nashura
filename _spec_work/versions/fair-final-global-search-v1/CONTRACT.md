# 全局随机快照与 Full128 搜索集成

本实验把已验收的 global-rng-snapshot-v1 引擎接入 history-v2 的真实搜索，
保留原 Full128 对局及冻结部署。使用原 general-provider 的 local 路径、固定
模型和预注册 tick110 根及其后继根；每根128次有效模拟，分别改变实际对局的
隐藏牌序，独立信念重建仍只读取 FAIR 历史。两对根共512次模拟。

新增传输审计只在创建、恢复、释放快照的控制边界读取摘要，不改变游戏推进、
模型推理或搜索选择。每次恢复必须逐字段匹配创建时的 tick、nativeSha256、
包含2504字节全局MT的 sha256 和明确 scope。generation/configRevision 必须
一致，stateEpoch 必须严格递增。所有创建的句柄都须释放，失败不补写成功记录。
审计记录属于独立证据区，不进入模型、候选生成、节点身份或 FAIR 历史。
记录每根搜索在各传输日志中的不重叠区间，独立验收要求每根至少128次恢复
命中该根完整摘要，并不少于其搜索生命周期报告的恢复次数，拒绝只核对总数。

启动前独立重验快照父证据和引擎构建。部署绑定所有源码、输入轨迹、配置及
引擎 SHA，使用严格 SSH host key，独立端口29791/29792，资源底线32GiB内存、
5GiB磁盘。进程绑定pid/start_ticks，只清理本实验所属进程。失联不当停机，
不自动重新启动。完整下载后独立核验每根128次有效模拟；不沿用旧32模拟训练契约。

限定范围：local、双ready、无pending预约的两个根，以及两次真实隐藏干预。
不替代完整搜索局、一般pending/fallback、全部随机机制覆盖、跨进程恢复、
模型强度或正式训练准入；training_admissible 与 gates_closed 始终 false。
既有有限测试及插件结果不因此升级为 G0/G1 整体通过。
