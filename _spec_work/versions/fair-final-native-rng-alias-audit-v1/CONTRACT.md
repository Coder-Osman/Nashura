# 随机初始化的跳转入口补充审计

本版本只读核对固定私有库，独立于运行中的搜索、采样及迁移部署。
原有18处MT初始化直接B/BL引用清单保持原样；它不是完整调用来源清单。

新审计从初始化入口反向追踪所有可执行PT_LOAD中的直接B/BL引用，遇到无条件B
继续把该指令地址视为等价转入入口，BL不作等价入口扩展。使用访问集合终止循环，
拒绝重复位置、非法指令类别及未对齐地址。这里只证明转入指令的语义，
不把EH范围当作单一函数或实际入口，也不证明每个地址实际执行。

固定库得到19条闭包边，较直接清单多出0x1a1cb30 → 0x7f5434 → 0x121b118。
0x1a1cb10处的完整36字节路径以time(NULL)返回值作为种子，将MT对象初始化到
可写LOAD内的全局地址0x19fc368。核对三段完整字节摘要、每条路径指令、time的
PLT及JUMP_SLOT符号。该路径未发现直接调用入口的证据，仍须研究fallthrough、
间接入口、调用者和全局对象消费者；未证明固定速猪实际使用，也未证明快照包含它。

这是一项补充风险清单证据，不表示已发现实际搜索结果受墙钟影响。
不得因找到额外时间路径就改运行引擎，也不得据此关闭FAIR/随机机制覆盖门。
剩余直接初始化引用、其它随机算法、全局生命周期、恢复和非干扰继续待验。

复核：在history-v2/project的PYTHONPATH下，运行alias_audit.py的
`--library PATH --output REPORT`及本目录pytest。公开库不含私有引擎，原生
重算及原生契约篡改测试在缺库时跳过，工程分析器测试仍运行。
