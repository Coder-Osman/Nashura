# 原生开局先验经验诊断 v1

独立实验仅补G0/G1的先验支持和开局分布证据；不训练、不运行搜索，
不修改Full128及迁移恢复的冻结部署。

- 预注册1024个比赛seed：SHA256("Nashura-G0G1-opening-prior-20261023:{index}")
  的前四字节按大端uint32解释，index为0至1023，要求互异。
- 固定速猪、基础形态、11级、公主塔，官方终局上限；每次重置预热至tick90。
  开局不提交任何策略动作，连接保持普通reset语义，不启用atomic-step限制。
- 第一原生进程采样1024次reset；完全清理后第二新原生进程复测前64个seed。
  记录双方4手牌+4循环、deckSlot和比赛seed；审计数据不进入训练加载器。
- 来源为字节冻结的history-v2/general运行时、固定SHA引擎；每段最大4小时，
  29777专属端口，至少32GiB可用内存和5GiB磁盘。正式中心200GiB门保持原义。
- 每行必须是八张牌的完整排列，cardId与deckSlot对应固定原卡组。每个seed
  都是一个样本单位，双方位置分开；不把同一seed的两方当独立重复样本。
- 事前固定21个卡方诊断：每方八个位置各8类、无序四手牌70类、首二牌56类；
  另有双方首牌联合64类。最小期望频数1024/70>5。族错误率0.01，Bonferroni
  阈值0.01/21。任何拒绝均如实报告，不重新挑seed或换检验来得到通过。
- 零假设为独立均匀八牌排列。未拒绝仅说明本次有限采样的这些统计量未发现
  偏离；不证明40320个排列均可达、不证明精确均匀、不证明历史条件后验。
- 跨进程重复只比较可观察的开局牌序；不同进程的隐藏RNG状态不据此视为相同。
- 收尾必须校验外部固定launch和下载回执SHA、来源SHA、完整行数/种子顺序、
  重算统计、跨进程重复及所属引擎清理。失败证据保留，整体门保持开放。
