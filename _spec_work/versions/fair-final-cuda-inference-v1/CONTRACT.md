# 冻结项目模型的五机CUDA工程检查

依据冻结ACCEPTANCE_GATES G0环境资源项；独立短任务，不启动正式迁移或五机actor。
使用已验收搜索前缀中首、中、末三个已提交边界的双方FAIR帧，固定源A checkpoint
e908f642bf1fda7bf0dca79a8d20d73ec2f56788a57f5d53739f13e2ae58d015。
源码、编译资源、帧、探针和权重逐项SHA锁定。临时部署与运行中的搜索目录隔离。

每机cuda:0执行同一source_policy适配器、完整编码器、策略条件头及WDL头，
与同机CPU对照。FP32关闭TF32，检查每个被测条件分布归一、非法质量为零，
固定RNG采样及贪心动作合法且CPU/GPU一致，参数和缓冲区摘要保持不变。
条件概率及WDL绝对误差上限1e-5，合法联合log_prob上限1e-4；失败保留现场。
覆盖所有可用卡的完整位置分布，以及首/中/末合法位置的延迟分布与首/末延迟联合概率。
此有限帧检查不宣称穷举完整联合空间、跨设备逐位一致、全部GPU可用、长时容量通过，
也不证明G2迁移模型或G3搜索强度。所有结果training_admissible=false、gates_closed=false。

部署使用每机/dev/shm下唯一目录，保留资源至少32GiB可用内存和512MiB临时余量；
这是可重建的小型推理现场，所有结果回传本机持久目录，临时盘不计入中心容量。
每机仅一个探针，运行上限180秒，不改动旧进程/权限/挂载或全局环境配置。
