# 全局MT初始化与快照覆盖的独立诊断

目标仅为补G0/G1隐藏随机状态清单。现有Full128、开局先验采样、迁移选优均保持原样。
冻结库SHA沿用110aa2b5…959783，探针SHA沿用49098dbf…095ba。

静态核对初始化数组中0x18e5370登记0x1335848；该入口保存真实LR，BL到
0x1a1cb0c后立即弹回真实LR，再顺序进入time(NULL)播种全局0x19fc368的路径。
这补齐旧alias审计的加载入口缺口，不追溯改写旧证据。三段消费者取随机数
路径绑定字节摘要，但不凭用途猜测或函数范围推断固定速猪实际执行它们。

独立新建两个原生引擎进程，顺序运行相同seed合法WAIT轨迹，分别在tick
90/1200/3600/5400检查2504字节全局MT对象。每个边界先建立快照，再将
第一个字节异或1；扰动期间没有游戏推进或决策。恢复后逐字节分类为原状态、
保留扰动或非预期状态；非预期状态失败。无论结果如何，退出前CAS修复原字节，
核验digest与句柄清理。该实验只改变新建实验引擎，不写运行任务的内存。

采用进程代次、tick、worker空闲、二进制SHA、映射与身份核验；三种过期身份
必须拒收。原生逐字节记录留在私有归档，公开只发布摘要和实现。
第二进程标志仅用于区分进程，不宣称15秒以内或指定墙钟延迟覆盖。

若保留扰动，只证明当前序列化/恢复对这块全局内存未恢复；尚须证明战斗
是否使用它、是否影响FAIR观察或搜索。若恢复原状态，只证明已测边界与
该对象，不升级为所有随机状态覆盖。无论结果，整体门、训练准入均保持false。
