## 2026-10-13 消费侧加速

学习器以32条决策为微批，共累积256条样本后更新一次。编码器按语义帧批处理，
所有正访问动作在原完整合法动作空间上批量评分，再按每条决策的访问比例计算CE。
WAIT、三分类标签、采样顺序、两倍样本预算、FP32、梯度裁剪与AdamW参数保持原契约。
先前可选的prior蒸馏实验仍走原逐条实现；本轮不启用该实验。

流式checkpoint的回放状态使用 `fair-search-replay.v2`，只保存有序对局引用、
语义身份、采样RNG和保留策略；完整对局首次写入同目录的
`replay-blobs/<semantic_sha256>.pt.gz`，后续存档复用不可变blob。
每次新增对局仍先提交恢复点，保留原断点边界；旧内嵌回放checkpoint可自动读取。
**训练恢复必须连同同目录的 `replay-blobs/` 一起保留/迁移**，并使用
`load_checkpoint(..., resume=True)`。单纯推理可独立携带 `.pt`，不需要回放blob。
恢复检查blob文件SHA和对局语义SHA；新引用仅在blob完整写入后原子发布。

`benchmark_learner.py` 在`.35`的V100上用同一初始权重、同一组256条真实决策，
交替执行两轮旧逐条实现/微批16/微批32。更新耗时中位数分别为82.015、3.208、1.910秒，
微批32的更新计算加速42.95倍，PyTorch峰值分配1.263GiB。
这是训练更新的A/B，不包含接收、校验、存档，不代表整局产出或端到端同倍率加速。
另对7条真实决策逐参数检查梯度，最大绝对差3.582e-6；损失通过FP32容差检查。
本地搜索、流式恢复、批处理及回放引用测试97项通过；微批默认调整为32后相关22项重验通过。

`manage_acceleration.py` 按进程路径核验身份，在已完成更新全部落盘的边界暂停、备份并
重启中心与学习器；五机actor继续运行。切换证据位于远端 `acceleration-20261013/`。
`learner-state.json` 新增最近接收/存档耗时，每次更新日志新增 `seconds` 与 `microbatch_size`。
