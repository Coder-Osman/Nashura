# 第0轮教师对初始教师：采样搜索评估

本实验比较完整教师的采样搜索策略，固定128局、64个交换位置种子对。第0轮学生过去的58.45%成绩属于双方贪心直出的独立评估，不作为本实验结果。

## 冻结条件

- A：`incumbent-000000.pt`，SHA256 `e908f642bf1fda7bf0dca79a8d20d73ec2f56788a57f5d53739f13e2ae58d015`；与原第128步最佳学生逐项相同。
- M0：干净实验初始教师，SHA256 `5ded4dbca4e7e0810613d025d8f911d6c86a6b7a62526e1b9955d80f53bcf552`；来源为新终局监督价值头模型 `671f2213401ae95a2464d0ad2d44bd67e00ad85e6331ca33397f06c75764a50b`。
- 每根32次模拟，1个FAIR世界，根噪声0，双方全局按原始 `N/32` 采样、温度1。搜索返回的argmax不用于实际执行。
- 比赛种子 `41614000..41614063`；已核对128,260个历史或预留种子，无重叠。
- 搜索RNG、动作执行RNG分离，按种子对编号、模型角色及本方决策序号绑定；换边保持模型对应的随机流。真实比赛种子不传入搜索器。
- 沿用既有教师对照实现：每个教师用自己的冻结模型生成候选、估值及模拟对手响应；未更换为获知对手搜索结果的响应器。
- 真实比赛CPU actor采用execution-only提交。每GPU一个服务同时常驻两个checkpoint，请求与缓存按SHA隔离；每局独占1个比赛引擎和2个信念引擎。

每机从1路开始，双方首根通过后分批增加，每批最多4路。保留32GiB可用内存和5GiB磁盘；持续换页、协议异常暂停相关分片。瞬时超时/连接异常最多尝试3次，原比赛及采样种子保持不变。每次尝试使用独立目录；失败不记平局。

按用户后续要求，五机总并发上限由124升至128，仅将.35从32增至36。通过独立 `run_host_capacity.py` 接管已运行的32个actor、96个引擎及7个双模型推理服务，再启动剩余4局；接管前后actor PID保持一致，原调度器停止。模型、搜索配置、128个任务及种子未变，原始manifest身份保留。扩容证据见 `capacity-handoff.json`、`capacity-adopted.json` 和 `capacity-result.json`；恢复.35扩容后的调度需沿用接管入口，普通入口仍采用原始32路上限。进程接管的4项Linux测试通过。

## 暂停与恢复边界

持续训练链和R2诊断链已停止，五机核验无所属残留进程。各旧目录的 `paused-for-teacher-r0-vs-m0.json` 保存进程身份、状态和任务清单，本地保存 `pause-result.json`。旧程序可能把SIGTERM记录成failed，以独立暂停记录为人工暂停依据。

保留已完成数据、checkpoint、优化器及训练游标；未来恢复未完成任务时沿用原种子并分配新尝试编号。此次评测及汇总器不恢复旧链、不更新模型、不写训练回放。

新评测supervisor重新运行时校验现存成功结果，按任务去重；原子完成记录存在则回收为完成任务，否则增加尝试编号。部署后冻结源码及配置；启动记录带PID和Linux start_ticks，停止时必须核验身份。

## 检查与报告

本地83项测试通过：新双教师21项、既有教师19项、原生回放43项。.34和.37现场各通过21项；其余三台缺少pytest，完成内置协议断言及真实checkpoint/引擎核验。五机877个引擎相关文件的汇总哈希一致。A的4个WDL参数张量均与M0不同。

正式首根证据保存在各会话 `first-roots-passed.json`，完整根访问记录保存在 `jobs/<job>/attempt-<n>/roots.jsonl`。中心每30秒校验并汇总结果；全部完成且supervisor清理结束后生成 `done.json` 和 `final-report.md`。

得分率为 `(胜 + 0.5×平) / 128`，以64个完整换边种子对作10,000次bootstrap，报告95%区间。下界高于50%支持A更强，上界低于50%支持退化，否则证据不足。即使教师退化，本实验也不单独证明价值头的因果作用。
