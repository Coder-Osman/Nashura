# 教师访问分布采样对直出策略

用户于2026-10-13要求停止教师采集，优先验证教师完整联合策略的实战强度。五机采集调度器、所属actor和引擎均已退出，124个完成回执及未完成任务现场保留；暂停证据在 `../teacher-continuation-20261013/pause-latest.json` 和各机 `collection-paused.json`。

## 冻结实验

- 教师与对手使用同一个冻结模型：SHA256 `671f2213401ae95a2464d0ad2d44bd67e00ad85e6331ca33397f06c75764a50b`，包含独立终局监督训练的新价值头；全程不更新权重。
- 1个FAIR信念世界，每根严格32次模拟，最低延迟、合法动作及同tick视图隔离复用正式运行时。
- 主组 `noisy`：复用采集配置的根噪声0.25、Dirichlet浓度10/K，搜索后从联合动作访问分布 `N(a)/32` 直接采样。
- 对照组 `clean`：关闭根噪声，搜索后同样从 `N(a)/32` 直接采样。
- 两组全局温度固定1，不使用采集行为在60秒后的温度0.5。此次测量的是被蒸馏的目标分布，不冒充原采集行为策略。
- 对手固定为相同策略权重的逐分量贪心直出，不搜索、不采样、不使用beam。
- 每组128局，64个独立比赛种子28614000–28614063，换边成对；两组使用相同种子。已核对本地已有采集manifest的任务种子无重叠。
- 搜索RNG保持现有按FAIR信息SHA及决策序号派生的规则；执行动作使用单独、域分隔的Python RNG，按任务/玩家/教师根序号派生。只从完整合法联合动作标识中按访问计数抽样，不独立采样动作分量。
- 每根记录完整稀疏访问计数、实际采样动作、argmax动作、采样种子、搜索耗时和tick。终局必须原生完整、无拒绝、无未确认；异常退出该机分片并保留证据。
