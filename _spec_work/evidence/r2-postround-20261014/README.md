## 固定定义

- A：历史干净闭环第128步学生，独立2000局对M0得分58.45%。
- B：持续训练第1轮学生，对A得分43.5%，未晋级。
- C2：持续训练第2轮第128步学生，对A得分48.375%，未晋级。
- Q：冻结第2轮结束时的A；本实验所有实战筛选/确认均对Q。
- 数据：历史124局、R1 124局、R2 124局，完整复制并校验。
- 审计：沿用各来源原始验证划分，共15+16+16局全部决策。
  逐局保留父模型累计曝光及各实验本次消费标记。
  原始验证集曾被用于选模，不能称为全新、未触碰的独立测试集。
- G2：相同A起点，继承/重置AdamW × 新数据/新旧各50%，均165步、batch256、FP32。
- G3：相同A和OPT_A、相同R2训练集和采样顺序，T=1/0.5/0。
  S1与E1完全相同，复用同一产物，不重复训练。
- 所有组固定单训练seed20261014，使用最终第165步做因素比较；不是C2逐位复现。
  R2基线C2按原协议是验证CE选出的第128步，两者明确区分。

## 有界执行

1. `lineage.py`冻结实际权重、优化器、回放和评测配对；门槛失败即停。
2. `preflight.py`在真实数据上解码27帧，并在原生引擎重放3局，逐决策核对FAIR信息与终局。
3. `runner.py`逐项完成G1→G2→G3→G4→G5；任何异常写BLOCKED，保留现场。
4. G1计算gate/ACT条件CE、教师前缀、端到端条件命中、完整合法动作排名、beam32及原生错例。
   完整排名使用条件概率前缀上界剪枝，绝不把候选集排名冒充全空间排名。
5. 四组G2和三组G3的起点、更新预算和数据合同分别冻结；训练16步保存恢复点。
6. 实战先跑预登记对照E1，再最多选一个G2组、一个G3组和一个解码候选。
   不以中途胜率增加样本。400局得分>50%才跑独立2000局；按配对95%下界判定。
7. 实战用独立端口33900起、最多8个本机评估进程，不抢占或关闭正式任务。
   失败原种子重试最多3次，保留每次尝试。内存32GiB/磁盘5GiB为停机门槛。

历史Replay的教师模型和状态分布与R2不同，虽然Clean标签合同相同，Replay因素结论仍需注明这个来源差异。
所有标签温度在完整动作上变换，WAIT为单个动作，Top-1平局使用字典序稳定裁决。
本实验不会读取私有引擎状态作为模型输入；真实比赛seed仅用于独立原生轨迹重放和评测。
