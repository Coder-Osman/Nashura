# 消费侧三组隔离实验

## 配置

- 采集与消费分开运行。新采集继续使用已验证的冻结教师，消费实验不更新采集权重。
- 训练输入固定为 `fair-new-value-teacher-20261012` 的原128局。新产出的512局暂存独立回放库，不在本轮中途改变数据集。
- 起点：`671f2213401ae95a2464d0ad2d44bd67e00ad85e6331ca33397f06c75764a50b`，新终局监督价值头和原策略权重，优化器重新初始化。
- 使用固定种子20261013和完整episode ID的哈希划分112局训练、16局验证。双方及同局所有时刻同属一组。
- 训练目标保持完整合法空间的策略CE加WDL价值CE，不锐化标签、不筛掉败方、不修改教师搜索。
- 三组最大更新预算均218步，每步256条，LR1e-4、AdamW、FP32、梯度裁剪1.0。
- 每64步和最终步骤验证，按整局等权策略CE选择最佳；连续3次验证未改善则早停，允许初始模型保持最佳。
- 额外记录策略KL、WDL CE、等待/出牌完整动作一致率、卡牌/格点/延迟分项、玩家位置和时间段。

## 三组

1. `stream`：沿用上一轮218步日志的到达节奏，验证局从所有更新中排除；已到达训练局中均匀选局，再有放回选决策。不是逐次复刻旧模型的训练，因为旧模型包含本次验证局。
2. `uniform`：所有112训练局从第一步可见，保持均匀选局、局内有放回随机采样，用于判断到达顺序的影响。
3. `balanced`：所有112训练局从第一步可见，优先选累计抽样最少的局，同局打乱遍历完再重复，用于判断曝光均衡及覆盖的影响。

均衡采样器也支持后续新局加入：新局曝光量落后时优先补齐；测试覆盖该行为。本轮正式流式学习器默认行为未替换，先完成隔离验证。

## 持久化与隔离

- 独立checkpoint类型 `fair-consumer-experiment.v1`，存模型、优化器、RNG、步数、剩余预算、每局每行曝光、局内排列与游标、验证历史和最佳版本。
- 冻结实验清单含原始episode压缩文件SHA、划分、初始模型SHA、配置、到达节奏及消费代码SHA；恢复时核对。
- 不修改原始搜索访问计数；不读取真实比赛私有审计作为模型输入。
- 每组保存 `latest.pt`、`best.pt`、`policy.pt`、`validation.json`、`done.json`。`policy.pt`为最佳验证模型的策略直出导出。
- 结束后仅标记等待独立评测，`promoted=false`，不会自动替换教师或线上模型。

新增测试覆盖晚到局补齐、局内无放回遍历、不同采样方式恢复、损坏游标拒绝、划分稳定、策略CE参考等价、三组中断恢复后模型逐张量完全一致、验证集隔离。

另外在`.35 cuda:7`完成真实数据流程验收：2局训练、1局验证，执行2个更新，完成初始与逐步验证、独立checkpoint保存及策略导出。此小数据验收的验证CE未改善，最佳版本正确保留在第0步；不将其当作正式效果实验。结果为本目录smoke-done.json。

这些工程测试不等同于胜率提升。离线结果优先比较同一步数和相同验证局，最终候选再使用未参与调参的成对种子直出评测。
