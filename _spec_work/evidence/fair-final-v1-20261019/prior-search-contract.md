# 先验接入Full128：独立工程验收

依据TRAINING_SPEC §2/§5与已验收prior-history-contract。保留旧provider、搜索器、
原生库及历史证据不变；新增PriorHistorySearchProvider只接受已验证先验构造器。

- 一个根构造一个独立世界，根内所有有效模拟与失败尝试使用该世界快照。
  下一根重新抽样；仅公开牌序支持集复用，不宣称原生局部重条件化。
- 世界承诺包含先验SHA、构造器身份、补全承诺、完整FAIR根/历史SHA、
  原生牌序验证以及冻结对手身份。构造证据异常在创建快照前失败并释放连接。
- 源A、固定基础速猪、FP32 CPU、默认6决策/200 tick软视野和6决策/60 tick
  扩展上限；每根128有效访问，根噪声0，执行按N/128独立随机流采样。
- 四个隔离分片为阈值1200/3600×双座位，各比较真实对手隐藏牌序扰动前后。
  共8根/1024有效模拟；逐边记录完整边界、回退、访问和根玩家价值视角。
  每次根恢复验证独立原生digest；记录一次世界构造和快照/连接释放。
- `.35`端口29652–29659，四片并行。启动内存≥64GiB，运行保留≥32GiB，
  磁盘≥5GiB；内部3540秒、worker3600秒、SSH4200秒上限，仅清理所属引擎。
  这是诊断资源门槛，不替代正式中心200GiB存储门槛。
- 独立attempt冻结源码、上传payload及先验身份；原始报告不可变。校验器
  重建抽样seed链与先验补全，核对访问总数及逐边轨迹，并以篡改负例验证。

排除总体先验质量、原生局部重条件化、正常单方ready根、加时根、整局搜索
强度、训练准入与端到端吞吐。全部产物training_admissible=false，G0/G1整体
仍在进行中。不因局部验收启动正式采集或发布模型。
