# 技能随机对象归属与完整轨迹实例检查

## 问题与结论边界

上一轮的`vtable 0x189f900 / +0xc0`只是定位线索，不应叫作通用组件随机源。
本轮沿原生反射、工厂和运行时虚表确认其为
`logic.data.actions.LogicActionGoblinsteinAbilityData`对应技能运行时。
固定速猪实验先检查实际实例，不为未出现的卡牌技能重复运行Full128扰动。

## 静态证据

固定库SHA沿用`110aa2b5cac391c498645e072b0d88729428c2c2845e7e2737ca8ee979059783`。
`native-action-random-layout.json`保存完整相关函数字节、指令、虚表重定位和类名，
校验器从固定二进制重新生成后逐项比对。

- 数据类虚表槽`0x188f2c8`指向反射函数`0xe6596c`，后续代码引用
  `0x2d2dcb`处完整类名；工厂槽`0x188f328`指向`0xe64fb8`。
- 工厂分配0xc8字节，调用`0xf4efc8`；构造函数设置目标虚表，
  基类构造将数据指针、所属实体分别保存在+0x18/+0x20。
- 技能初始化`0xf4f0ec`把`tick×12345`传给随机seed设置函数；设置函数本身
  还读取全局时间相关状态，所以该参数不等同于最终状态，亦不证明只由tick决定。
- 虚表+0xe8/+0xf0指向保存`0xf4f9b4`与恢复`0xf4faa0`；所查直接序列化代码
  未保存+0xc0。尚未证明外围/间接处理，也未在含该卡牌的局面做扰动恢复。
  因而保留“其他卡牌快照覆盖待查”项，不将其当作本实验快照已坏的事实。

## 原生检查

`.35`、独立端口29649、一个引擎。源A、固定速猪、基础形态和11级沿用已验证配置。
从FIRST_PLAYABLE_TICK到原生finalized，在全部决策点、四个指定阶段tick和终局
进行只读对象检查，采样协议为`every-decision-plus-stage-and-terminal.v1`。

先核验PID/start_ticks、cwd、端口、QEMU命令、原生库SHA、执行代次、epoch、tick及worker空闲。
使用已有暂停守卫，并仅以O_RDONLY打开进程内存；不增加生产观察字段。
从manager→world→塔→对象管理器取得有界实体向量，校验实体ID唯一；
沿entity+0x28技能队列及queue+0x50向量遍历，验证runtime+0x20的所属实体回指。
记录全部技能虚表计数；只有目标虚表精确匹配才读取+0xc0随机字段。
若目标出现，立即保存现场并失败结束，不在未证明快照覆盖前写入该字段。

100/1200/3600/5400四阶段另验证观察、digest与对象清单在只读检查前后相同，
原生快照恢复后的清单与digest一致，并释放句柄。
内部1200秒、外部1260秒上限；≥32GiB可用内存、≥5GiB磁盘；仅清理所属引擎。

## 验收及非目标

样本tick必须精确等于“决策tick集合∪四阶段tick∪终局tick”，无重复或缺漏，
双方有决策、终局原生finalized，
所有技能实例都校验所属实体，所有目标计数为零；运行时总观察数须大于零，
防止空遍历被误认成功。四阶段快照证据、源码和部署身份、进程清理均严格核验。
负例覆盖删tick、重复tick、目标实例、错误计数/进程、状态写入、缺阶段、
恢复不同、句柄泄漏、非完整终局、错误标签、缺座位、身份篡改、训练资格误标等。

通过只支持“这条完整固定速猪轨迹的全部决策点及指定阶段/终局采样点未出现目标技能”。
不排除采样点之间或tick内部短暂创建销毁，不推广到所有比赛种子、其他卡牌或全部随机源。
不证明目标技能的随机字段可由现有快照恢复；不发布训练数据，G0/G1保持进行中。
