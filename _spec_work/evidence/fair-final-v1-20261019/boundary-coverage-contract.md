# 正常决策边界闭包：限定工程证据

依据冻结 TRAINING_SPEC.md §1 的原生合法动作、到期先结算、公开事件抢占和
真实 DecisionBoundary 规则，验证正常完整局是否需要单方 ready 根。
本项不改变规则、搜索预算、引擎和训练准入。

## 时序前提与穷举

同步开局，双方冻结视图后同 tick 原子提交；WAIT 固定 60 tick，ACT 延迟为
2–60 偶数 tick。成功 ACT 必须产生双方可见的公开部署事件，且无拒绝、无
未确认执行。在这些前提下，第一次到期的 ACT 唤醒双方；更早的公开事件
抢占双方预约；双方 WAIT 同时到期，所以下一个非终局决策仍双方 ready。

boundary_reachability.py 使用真实 DecisionClock 枚举 31×31×61=58,621 种
动作/公开唤醒时序。独立校验器以 min(双方截止时间, 公开唤醒时间) 重算
边界 tick 分布，并绑定源文件 SHA。拒绝和非公开成功执行两个反例明确保留：
它们会产生单方 ready，因此结论不外推到一般单方/pending 搜索分支。

## 原生完整轨迹

固定源 A，独立 phase-snapshot 引擎，完整合法分布采样一局、纯 WAIT 一局。
冻结双方视图后采样并原子提交；每 tick 保存执行结果、公开事件、预约证据、
ready 和终局标志；每组保存动作、FAIR 摘要和双边原生 hand/cycle 长度。
完整原生结果、私有诊断种子、部署身份及引擎清理证据均独立归档。

独立校验器从开局重放 DecisionClock，核对 tick 连续性、全部预约结算、
公开执行事件与 ACT 逐项对应、双方 ready、最终时钟和胜平负标签。
合法性由冻结版本探针在实际掩码上校验；该轻量审计轨迹只保存摘要，
不是可供学习器使用的完整训练帧。

本次采样局 175 组/350 决策，玩家1获胜，145 次执行、131 次正常抢占；
WAIT 局 99 组/198 决策，真实平局。合计 274 组、548 决策、12,015 tick。
32 类负例覆盖原生轨迹和时序前提，修改轨迹后重算摘要仍必须拒收。

## 新定位的补牌缺口

采样局 tick110/2598/5602 有 3 组双方 ready 根出现玩家1 hand=3、cycle=5；
该状态是合法真实决策边界。
现有 SettledDrawReconditioner 要求双方 hand=4、cycle=4，故尚未覆盖这些根。
下一项需核验原生补牌计时/槽位、条件化后的隐藏牌一致性和快照恢复，
支持该边界；不得提前推进、强制补牌、忽略该行或复制真实私有状态。

已定位接口：原生 read_player_state 读取四个手牌槽，build_observation_json
省略负数空槽但保留其余 handIndex；resident_belief_draw.inc 已接受 -1 空槽，
并对补牌数量、cycle长度、generation/epoch/tick 做 compare-and-swap 检查。
尚未证明的是补全算法与延迟补牌的对应关系，不是仅放宽 Python 长度判断。
PublicCycleBelief 当前在公开出牌后立即逻辑轮转，initial_draw 仅接受4+4；
因此需要单独区分逻辑牌序与原生当前可用手牌。

后续实现顺序：先用固定轨迹重放上述三根，记录独立信念引擎的空槽与连续
补牌变化；再确定由公开历史约束的FIFO补全映射，保留锚点的空槽位置和
原生计时；最后对双座位进行A/B/A替换、重复恢复续演及Full128隐藏扰动。
真实比赛原始牌序只用于独立审计，不进入补全映射。若独立重放在根处与
本方完整FAIR信息不一致，保留失败证据，继续修正重建路径。

## 验收边界

只放行 G0.NORMAL_BOUNDARY_REACHABILITY_SUBSET。G0/G1 整体仍进行中，
training_admissible=false。两局不证明所有随机种子的原生行为；条件闭包不
证明一般 pending 世界补全、拒绝搜索分支、完整局搜索质量或训练强度。
原生异常保留现场并失败；不会用穷举前提覆盖原生反例。
