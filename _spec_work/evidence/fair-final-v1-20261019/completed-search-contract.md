# 完成边界搜索与开局原生子项

本模块依照TRAINING_SPEC.md §§2、5.1–5.6实现独立搜索，不替换旧搜索/旧PPO。
Full128/Fast16计数和数据格式复用新版SearchResult/v1契约。

## 实现

- 每根只创建一个独立信念世界；每次模拟恢复该世界，绝不从真实比赛拷贝完整状态。
- 根和己方后续节点使用FAIR帧/合法掩码摘要、己方动作和信息历史链索引，
  原生句柄、世界身份、真实seed均不进入节点键或候选生成。
- 先构建固定32上限候选池，WAIT和每张可行动卡的代表动作优先开放；
  随访问增加开放其它候选，不重算先验分母。PUCT=1.5，默认无噪声；
  可配置ACT内部噪声但保持WAIT/ACT总质量，协议SHA绑定所有预算和开放规则。
- 双边先冻结观察，冻结对手仅收到自身DecisionInformation，采样后整组提交。
  搜索RNG、世界RNG、对手RNG、候选RNG和实际执行RNG分别派生。
- 树只优化根玩家；跨对手单独唤醒时保持己方预约，等待执行/抢占/拒绝/WAIT到期；
  只有已结算边才进入回传路径。WDL按根玩家视角，不因事件次数翻转。
- 软上限6组事件决策/200tick，硬延长默认6组/60tick，全部版本化。
  超硬界时恢复最近己方完整边界，放弃该边，只向已完成前缀回传边界价值。
  根边未完成不计访问，默认累计32次无效尝试后隔离，墙钟超时不返回半预算标签。
- Full恰好128有效根访问，Fast恰好16且policy_target为空；正式执行均按访问数温度1采样。
  完整候选、原始logp、投影先验、噪声先验、N/Q、世界承诺和对手身份一并保留。
- 每个转移使用完整RolloutSnapshot；失败时有界退出，世界关闭恢复并释放根快照。

## 本轮原生验收范围

`OpeningBeliefProvider`仅支持无动作开局：由本方FAIR观察中的手牌和可见牌序
条件化独立引擎初始化。实验卡组先验固定速猪；这是明确的实验先验，
不是读取真实对手卡组，也不是通用经验卡组先验。中后段根显式拒收，
没有用复制实际比赛状态作兜底。

原生验收使用源A适配器和独立端口29624/29625。双方分别做真实隐藏牌序交换前后
两次完整Full128根，候选、N、Q、执行动作和目标精确比较。真实比赛digest保持不动。
为限制工程验收耗时，本探针使用2组/60tick软视野、6组/60tick延长，
与默认6组/200tick不同，单独保存协议SHA，不称为正式搜索棋力评测。

## 剩余门槛

- 中后段兼容历史重建、增量信念同步、模拟对手隐藏计划重建与一般卡组先验仍待接线。
- 原生PRNG及所有隐藏机制未做穷尽扰动。
- 默认完整视野、搜索整局质量与迁移WDL校准尚未验收，不启动五机正式采集。
- 搜索工程正确性、教师标签质量和学生实战提升是不同门槛；本项不证明模型更强。
- 本轮报告与所有测试均为工程验收，不发布checkpoint，不向正式Replay投递数据。
