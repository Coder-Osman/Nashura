# 学生补充轮采集接口：限定工程验收

依据冻结TRAINING_SPEC.md §4.3：补充轮行为为学生贪心对A适配器贪心，
记录的监督仍来自冻结A，不把学生实际选择写成教师动作。
本次只验证接口，G2正式1280局、模型保真、WDL校准及实战非劣均未启动。

## 实现与边界

- 独立入口firstlight_CR/tools/fair_migration_supplement.py支持round1/2；
  原round0 collector默认行为保持不变。入口强制engineering-acceptance。
- 检查学生FP32、eval、冻结参数、网络/catalog及来源身份；加载网络时不恢复
  父训练器的优化器、RNG或游标。父数据集与检查点严格绑定。
- 轮次连续、namespace/协议/card_ids一致；同轮使用一个冻结学生，
  每个种子对恰好两个相反座位；当前任务及配对ID与相邻父轮互斥。
  尚未实现所有历史轮次的全局防重叠与正式轮次协调。
- 同tick先冻结双方视图，再分别选择并统一提交；行为动作和A完整软条件
  分布引用、贪心标签及WDL分开记录。正常抢占保留，拒绝、截断及不完整终局隔离。
- 只在完整原生终局后原子发布整局；本次全部training_admissible=false，
  不进入正式Replay，不更新或替换模型。
