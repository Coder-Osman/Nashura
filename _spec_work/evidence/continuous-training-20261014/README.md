# 124路持续FAIR训练

用户于2026-10-14授权启动持续循环，不设置总时长或轮次上限。每轮冻结模型，五机以4/32/32/24/32路采集124局，双方1个信念世界、每根32次模拟、根噪声0、全程按N/32独立采样。

起点为上一轮独立2000局确认得分58.45%的第128步候选。完整策略、编码器、WDL参数与所选checkpoint一致，保留该步AdamW状态；继承已完成预算的216条余量。导出checkpoint身份为 `e908f642bf1fda7bf0dca79a8d20d73ec2f56788a57f5d53739f13e2ae58d015`。

## 每轮流程

1. 冻结新124个采集任务、108局训练/16局验证划分、400局筛选及2000局确认的种子。与已扫描历史种子及本循环所有既有轮次避重。已生成清单在重启时复用。
2. 每机首根检查32次访问和独立动作采样，通过后逐步扩容至配额。完整有效局中心校验、去重，124局全数验收后开始学习。
3. 编码器、策略、WDL联合训练，FP32、AdamW 1e-4、weight decay 1e-4、有效batch256、clip1.0。采样按整局均衡并局内轮转，预算为训练行数两倍加继承余量，余数结转。继承现任模型的优化器；本轮中断恢复读取本轮latest.pt，保存采样游标、RNG及预算。
4. 第0/64/128/.../最后一步验证；按整局等权策略CE选候选。400局贪心直出对现任贪心直出，得分高于50%才执行独立2000局确认。完整配对95%置信区间下界高于50%才晋级。第0步且参数不变跳过自身评估。
5. 晋级时导出所选候选完整模型及对应优化器；未通过时保留现任模型。写本轮promotion.json及中心cursor.json，继续下一轮，不自动修改本实验之外的线上部署。

当前复用本轮124局消费方式，每轮仅消费当轮训练划分，保留历史整局与checkpoint供复查；不混入之前失败学生数据。恢复操作不会重复完成的训练或评估。

## 性能版本

- 真实动作直接提交执行账本，actor在socket推理模式使用CPU模型，不再本地重复编码或写PPO记录。
- 换根成功后只保留当前根解码缓存；捕获、快照创建或摘要失败时保留旧根缓存。保留当前根供32次恢复复用，不清除训练信息历史。
- 候选采样将GPU计算的FP64累计概率缓存到CPU，在CPU进行随机阈值选取。条件分布仍由原GPU模型计算；只有缓存缺失时上传条件索引。保持原随机流、候选顺序与完整合法动作分布，不引入Top-K。
- 真实模型48个请求、6个阶段帧、6轮交替测试：动作与候选一致，先验使用现有相对2e-5/绝对1e-7容差；请求中位2.931→2.506秒，1.17倍。此为缓存推理测试，不是整局倍率。严格逐位检查的前两次诊断失败记录保留，未进入训练。

本次真实引擎对照新旧各6个根、每根32次访问，信息摘要、完整访问分布、所选动作及执行随机种子一致。两个信念缓存分别由3条降为1条；新版actor本地编码和概率评估均为0、未初始化CUDA，PSS约500MiB。旧路径PSS约1242MiB。6根累计搜索耗时233.80→220.79秒，仅为单组短窗口诊断；不将其宣称为完整采集吞吐倍率。诊断actor、服务及原生引擎均退出。

相关本地测试174项通过，涵盖缓存失败换根、采样参考一致性、搜索、合法性、取消、终局、训练预算、优化器继承、验证隔离和中断恢复。起点全部模型与优化器张量逐项相等，证据见 `bootstrap-passed.json`；搜索证据见 `search-passed.json`，候选采样计时见 `sampling-passed.json`。
