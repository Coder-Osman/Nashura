# SSPI 无搜索价值训练：当前 WL 协议与历史 WDL 结果

本文描述独立value-only实验，其中价值训练仍更新共享层。新增加的“每代SSPI之后仅训练价值头”阶段采用更严格的冻结范围，见[追加阶段协议](SSPI_DIRECT_VALUE_STAGE_2026-11-03.md)；两种运行身份和数据保持分离。

## 当前主线：仅胜／负二分类

本轮仅实现、测试和发布代码，未启动新实验。当前价值头为 `value_head: 512→256→2`，类别固定 `WIN=0, LOSS=1`。共享主干、FAIR 输入、五档延迟、补牌与 WAIT/PLAY/ABILITY 协议不变。SSPI 搜索叶值采用 `P(WIN)-P(LOSS)`，真实平局终局按已知规则返回 0。旧 FAIR 搜索通过显式三类协议保持历史兼容。

value-only 仍为全 DIRECT、独立 50% 价值采样、冻结当代策略、冻结策略头参数、仅共享层及价值头更新。自然平局在真实终局后整局清除搜索根、派生点及价值状态，只保留终局/动作账本和排除计数；不会为过滤增加观测、决策或随机数消耗。失败、截断继续隔离。每代固定采集 64 局训练和 16 局验证，平局不触发补采；统计采集局数、有效胜负局数、排除平局数。有效训练或验证样本为空则记录 skipped，不更新、不保存新 checkpoint、不继续下一代。

每代保留全部训练样本一次曝光、batch128/microbatch4、AdamW lr=1e-4/weight_decay=1e-4、clip1。每32步与代末比较独立验证 WL CE，恢复最佳模型和对应 AdamW 状态；没有改善时回滚并报告失败。策略头 SHA 保持不变，共享层引起的 WAIT 概率和模式级 KL 漂移另行记录（不是完整联合动作 KL）。

价值检验使用两类 CE、两类平方误差之和定义的 Brier、10 档 ECE，与随机初始模型及由训练集胜负样本频率计算的加一平滑常数基线比较；CE 差值置信区间按完整 episode bootstrap。最后16局价值留出也包含两种基线和区间。均匀二分类 CE=ln(2)≈0.69315，Brier=0.5；删除 DRAW 本身不是学到局面价值的证据。

以后运行配对评估时仍使用预定1500独立种子对、3000局，记录每对的胜局数和有效胜负局数。主指标为总胜局/总有效胜负局，按完整种子对 bootstrap；自然平局不计半分，不补采替换。全平局时指标为 null/undefined，bootstrap 零分母次数可由请求次数与有效次数之差取得。WL 概率是胜负局条件下的估计。

## 版本与恢复边界

- 模型：`sspi-policy-value.v3`，`value_order=[WIN,LOSS]`；checkpoint：`sspi-mac-pilot-checkpoint.v3`。
- 搜索 episode：`sspi-mac-pilot-episode.v2`；value-only episode：`sspi-value-only-episode.v2`；标签字段 `wl`，内存类型 `WLLabel`，不接受旧 DRAW 枚举。
- value-only run/generation、SSPI run/generation、配对评估均升级为 v2；CLI 要求显式新 run_id。旧三分类模型/样本不会自动转换；旧运行的状态文件也不会被新 value-only CLI 的拒绝加载覆盖。
- 尚未决定下次实验的随机重启或迁移策略，未创建新的运行或训练 checkpoint。旧 v1 run 与第1代权重原样保留。

## 历史 WDL v1：第1代已完成，结果不改写

下面的架构、WDL指标与运行身份仅属于此前三分类版本，不作为二分类结果。

本实验与 5% × 128 SEARCH 训练分开记录。固定 2.6 速猪、SSPI FAIR 输入、五档 PLAY 延迟和随机初始化 seed `20261103`。每个真实决策均从当代冻结网络的合法联合策略采样；双方各决策独立以 50% 概率保存行动前 FAIR 状态，只有完整自然终局后才附加该玩家 WDL。样本门控不影响动作，也不增加决策或观测。没有 MCTS、访问目标、策略 CE、奖励塑形或额外历史事件序列。

模型架构不变。`policy_head` 参数不进入 AdamW；价值 CE 更新共享编码器、手牌投影、主干和 WDL 头。因此策略输出可能经共享层间接漂移，不能把胜率变化归因于显式策略优化。每代先冻结采集 64 局训练、16 局验证，再把该代入选训练点确定性打乱，各使用一次；batch 128、microbatch 4、AdamW `1e-4`、梯度裁剪 1。每 32 个优化步和最后一步按独立验证 WDL CE 选择最佳模型及优化器状态；没有优于代初的状态则回滚并停止。总计划 8 代，最后另有 16 局当代策略价值留出集和 1500 对/3000 局换边无搜索评估。价值验证以 WDL CE、Brier、10 档校准和按完整局 bootstrap 为主，胜率仅作观察。

运行身份为 `sspi-value-only-50pct-64x8-20261103-v1`，初始模型 SHA256 `9e17519d536c1aa1a7d6879b8d0468f508ee0f396e01645fdd93e4b32ac445e4`，初始策略头 SHA `7cc61795870493f85452e0d8492945cd6b845d2d0c9010ea567418418485a7d2`。macOS M4 Max 宿主以 CPU 推理/更新，通过 `event-json-delta` 和 adb forward 连接隔离 ARM64 AVD `emulator-5556` 的 actual 端口 26889；原生 `libg.so` SHA256 `110aa2b5cac391c498645e072b0d88729428c2c2845e7e2737ca8ee979059783`，probe SHA256 `f79ba9344a9599483c7283e7cde756a3a77f2982741f0c83467eee68a1f28e64`。probe、APK、权重和完整 episode 只在本机保存。

先运行 3 局独立完整 validation 诊断，均为 0 SEARCH；已通过 episode/账本/终局标签的校验加载。这 3 局不进入正式训练或验证。真实墙钟分别为 17.790、10.684、19.512 秒，入选价值点分别为 360、195、382，episode 张量文件分别约 50.3、27.2、53.4 MB。首局互斥计时中，策略推理 6.422 秒、runtime advance 4.922 秒、冻结边界构造 3.599 秒、样本序列化与落盘 0.609 秒；其余由动作记录、采样、setup 等组成，嵌套的 native bind 不与 advance 重复相加。这是 3 局局部测速，不是 64×8 吞吐结论。

独立诊断用一局的 360 个样本更新、另一局的 195 个点验证，3 次 AdamW 更新后 WDL CE 为 `1.09847 → 1.06123`；该模型不属于正式训练运行，不作为实战强度证据。工程定向回归包含原 SSPI 搜索/训练及新价值协议，共 `104 passed`。正式代际、checkpoint 和最终评估结果应以运行目录内的完整记录另行补充。


历史 v1 第1代最终完成64局训练（17,041个入选状态）和16局验证（4,241状态），全部自然胜负终局、0平局、0 SEARCH。尝试134步，保留第96步的模型及AdamW。验证WDL CE为1.098323714→0.695379929，训练频率常数基线为0.693208110；尚未优于常数基线，未证明状态价值预测或实战强度改善。固定32验证状态WAIT概率0.704977349→0.775478881，属于共享层间接漂移。没有继续第二代和最终3000局评估。
