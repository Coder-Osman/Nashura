# 第1755轮 IL+RL 价值头塔血输入敏感性（2026-11-05）

使用第1755轮事件策略 checkpoint，SHA-256 `e9f7c84a3e5f84a4d625c3f9a68e332a318a2aedc06e196da55bdb00a66bd1f0`，模型共9,953,219个参数。checkpoint 的 value head 输出无固定上下界的标量，并非 SSPI 的 WIN/LOSS 概率。它所用的 RL reward contract 包含系数0.15的可见塔血势函数（国王权重3、公主塔权重1、gamma 0.999），这是解释敏感性的训练背景。

探针读取一条经校验的 on-policy native shard：自然完成的一局提供134个按 actor 视角记录的状态（69个执行动作、31个WAIT、34个取消执行请求；截断0）。每个状态依次将双方公主塔、国王塔及全部存活塔的HP保留率设为`1.00/0.75/0.50/0.25/0.10`。归一化HP与绝对HP同步缩放；塔身份、存活掩码、激活状态、场上单位、空间输入、手牌、圣水等其它字段逐位不变。未把塔置零、不制造摧毁事件。这里只做CPU推理，不训练、不采集新局，也不连接AVD或引擎。

| 干预 | 减半时平均价值变化 | 方向正确的状态比例 | 五档单调状态比例 |
|---|---:|---:|---:|
| 己方公主塔 | -0.5479 | 100% | 100% |
| 敌方公主塔 | +0.1891 | 100% | 97.76% |
| 己方国王塔 | -0.1550 | 99.25% | 95.52% |
| 敌方国王塔 | +0.1144 | 100% | 96.27% |
| 己方全部塔 | -0.6884 | 100% | 100% |
| 敌方全部塔 | +0.2109 | 100% | 100% |

例如第0条观测（tick 390），原始 critic 输出为`-0.2713`；只把己方两座公主塔HP减半后为`-0.7397`，只把敌方两座公主塔HP减半后为`-0.0548`。因此，这个 checkpoint 的价值计算明显读取塔血，且绝大多数变化符合“己方塔血更高有利、敌方塔血更低有利”的方向。

结果同时显示幅度并不对称：己方公主塔减半的平均影响约为敌方公主塔的2.9倍。旧策略使用塔血塑形奖励，所以网络对塔血敏感并不意外；但这个探针不能区分学习到的策略价值、塑形回报特征和数据分布偏差，也不能将标量解释成胜率。按retention区间在单个状态内做了相同的HP插值，所有134个样本都是同一局的相关观测，不提供独立对局置信区间。静态改HP也不模拟未来战斗，国王塔干预尤其可能与塔激活状态不一致。

以输入自动微分和中心有限差分检查己方/敌方公主塔HP方向，最大导数绝对误差为`3.2e-4`；所有134帧的原始张量、checkpoint、参数及缓冲区保持不变，重复前向最大误差为0。11项新增专项测试、主工程495项回归和公开工程1,104项通过（公开套件42项既有skip）。完整逐状态结果和权重留在本机私有目录；本公开摘要不包含原始对局输入或 checkpoint。

诊断脚本：[event_value_sensitivity.py](../firstlight_CR/native_runner/training/event_value_sensitivity.py)；专项测试：[test_event_value_sensitivity.py](../firstlight_CR/native_runner/tests/test_event_value_sensitivity.py)。这是一项输入敏感性检查，不是拟合验收、策略强度评估或胜率实验。


## 复现范围和身份

- 模型为 `event-checkpoint.v3`，snapshot-only，两层残差块。总参数9,953,219；价值头`512 → 256 → 1`。没有沿用当前SSPI二类价值语义。
- 第1755轮权重采集的存档目录名含1756，表示准备下一轮更新；采集contract明确绑定1755 checkpoint及模型协议SHA。数据与权重身份均在推理前验证。
- 只使用一个完整对局、owner 0视角的134条观测，tick范围390–5995；其中100条动作执行或WAIT，另34条随后取消执行，均为真实决策时输入。单独过滤为100条有效执行/WAIT后，公主塔减半的平均变化分别为己方-0.5570、敌方+0.1860，两者100%方向正确。取消动作没有被当作训练样本；本次无任何参数更新。
- 源存档使用FP16储存特征，推理恢复为FP32，两路HP特征按同一比例缩放而保留原舍入关系。所有六塔身份/阵营验证完整；padding和已摧毁塔不干预。
- 14个explicit spatial通道仅由普通entities生成；塔的原生HP由`towers.features[...,0]`及`[...,5]`进入tower token，经关系Transformer传播至scene与candidate表示，再进入共享主体及scene-to-value旁路。空间编码器的learned scatter仅接收child_memory；此次塔血干预不修改该分支输入，完整前向按原网络重算。
- 保留原始activation和历史字段是为了隔离当前HP输入；尤其降低未激活国王塔HP可能落到非自然组合。因而公主塔结果是主要证据，国王塔扫描只作扩展诊断，不声称任意干预状态都能原生到达。
- 主要计算在Mac ARM64 CPU单线程、Python3.13.5/PyTorch2.9.0执行，约306.35秒；同机同时运行发布检查，非性能benchmark。

## 势函数偏移

旧奖励为`r + 0.15*(gamma*Phi(next)-Phi(current))`，终局Phi置零。对精确折扣回报，势函数项望远镜求和给出当前值的`-0.15*Phi(current)`偏移。因此另报`V + 0.15*Phi`诊断，其中`Phi`使用旧协议的国王权重3、公主塔权重1，并除以5。它仍包含其它奖励项，不是胜率，也不是已验证的校准后真实价值。

该诊断中，己方/敌方公主塔减半的平均变化分别为`-0.5722/+0.2093`，方向结论不变。探针不能据此分解模型的学习来源；旧IL+RL中采用过塔血奖励塑形，新SSPI纯终局价值训练并非同一训练目标。
