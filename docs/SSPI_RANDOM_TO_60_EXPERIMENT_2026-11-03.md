# SSPI 随机初始化至60%直出胜率：实验设计

状态：**设计稿，尚未启动；若干调度与评估功能仍待实现。** 代码阅读基准为 `main@6e54b381ad8aadc3ef6ef30fdfdfcfca3d354e62`。配套可读配置见 `SSPI_RANDOM_TO_60_PLAN_2026-11-03.json`；它不是当前CLI可以直接执行的run_config。

## 1. 目标、比较对象与成功口径

目标是在既有 SSPI + 代末直出价值头阶段下，从seed20261103的全新随机参数开始，尽快获得对固定初始策略theta0至少60%的**无搜索胜率**。双方同固定2.6速猪、FAIR输入、动作/补牌规则和温度1合法联合分布采样；theta0是相同初始化生成的冻结神经策略，不是另造的均匀随机或弱化对手。

样本胜率为W/(W+L)，自然平局单独排除并报告；失败、截断、隔离局不产生胜负。训练与评估全部使用本次新运行数据，不加载旧模型、优化器或训练episode。本设计不承诺一定达到60%，8轮是首个里程碑，不是保证收敛次数或硬性训练时长上限。

两级结论严格分开：开发筛查的点估计达到60%只是候选信号；正式验收要求在独立新种子对上通过预登记的单侧序贯检验，拒绝真实条件胜率p≤0.60。单个初始化seed成功仅说明该次运行学到了可测的改进，不外推所有初始化。

本实验没有训练框架对照组。若成功，可证明这条完整路径能从随机起点达到目标；不能单独把收益归因于新增价值阶段、更多根曝光或学习率调整中的某一项。

## 2. 设计依据与现有浪费

历史三分类run `sspi-mac-5pct128-8x8-20261103-v3` 的G1/G2各8局训练，分别产生210/159个搜索根，却各只训练128根；共369根中113根未更新，未使用比例30.62%。当前 `experiment.py` 仍只抽一个128根batch做一次联合更新。

旧首代曾在1e-4 AdamW一步后出现WAIT偏置过冲；离线稳定性重放接受的是1/8参数步长。故新方案先将联合基础学习率降为1e-5，并充分使用当代搜索根。此数值是基于现有证据的保守首选，不是已证明最优超参数。架构、搜索预算、损失定义及终局语义不变。

不增加额外预训练阶段：G1直接从随机模型采集，G1末追加价值学习给G2搜索提供新的估值。独立value-only历史上从1.098降到约0.695仍未胜过常数基线；本次二分类必须比较状态预测与训练频率常数基线，而不是把删除DRAW或拟合类别频率当成学会局面价值。

尚未验证的关键假设是：冻结当前共享表征后的价值头能学到超越类别频率的状态信息；这种估值能帮助128次有限搜索产生更好的动作目标；联合模仿又能将改进传递给直出策略。全根最多两遍提高数据利用率，不增加独立终局的数量，也不保证教师更强。每个环节均以对应验证指标检查，不把单纯增加梯度步数等同于胜率提升。

## 4. 选模与快速正式验收

开发筛查位于G1/G2/G4/G8，各使用64个独立种子对、两次换边。各检查点种子域分开；结果只用来筛查、诊断和选模，不作最终显著性证据，不把不同checkpoint的对局混在一个胜率里。

选择规则在启动前固定：第一个开发胜率≥65%的检查点进入正式验收；若到G8均未达到65%，从已筛查的检查点中选择开发胜率最高且≥60%者，相同则选择更早代，否则本阶段没有正式候选。用于选模的该次筛查须至少有64局有效胜负局，数量不足或全平局不触发选模，也不补采。65%只是为60%验收留余量的筛查阈值，不意味着已证明达到65%。

一次本实验只选一个正式候选；候选checkpoint/策略/对手theta0/温度/引擎版本/源码与评估种子域全部锁定。正式数据与训练、验证、开发筛查全部分离。至少64对/128局，最多1500对/3000局，每32个**完整**种子对写一次报告，并可在达到以下门槛时提前结束。没有达到门槛则报告未证实目标；不在同一正式数据上重新挑checkpoint、变温度或变对手。

### 提前停止规则：以完整换边种子对为统计单位

为避免普通95%区间反复查看带来的假阳性膨胀，采用固定的非负检验鞅混合。它只是评估统计，不改变训练方法。

第i对定义W_i为候选获胜局数，D_i为有效胜负局数，因此0≤W_i≤D_i≤2。设X_i=W_i−0.60D_i，取预先固定的Λ={0.05,0.10,0.20,0.40,0.80}，计算：

`E_n = mean_over_lambda(product_i(1 + lambda * X_i))`

实现时累加log1p并使用log-sum-exp，避免长评估下的溢出。在H0: E[W_i]/E[D_i]≤0.60、完整种子对独立同分布且候选固定的条件下，E[X_i]≤0，因子最小为0.04，故每个乘积以及其固定混合均为起点1的非负supermartingale。Ville不等式给出H0下任意时刻跨过20的概率≤0.05。

**正式通过：已完成至少64个种子对、有有效胜负局，且E_n≥20。** 这支持真实条件胜率高于60%；单纯观察到60%点估计不算通过。成对bootstrap区间继续作为描述性报告，不用它在反复查看中挑停止时间。

双方平局的一对D_i=0，其因子为1，不产生证据；部分平局按该对实际W_i/D_i记录，不将平局算半胜。失败或截断使该对未完成，暂停并保留证据，不跳过并替换种子。统计程序须绑定每对账本、checkpoint SHA和配对身份，恢复时每对只累计一次。

此错误率保证依赖独立的新种子对、固定候选和预登记规则。正式失败后若要测试新候选，应另行登记跨候选的错误率分配；不反复重开5%检验直到通过。

## 5. 诊断和继续条件

- 每代报告真实搜索根数、使用/未用/尝试/接受曝光数、接受步数、回退比例、训练与独立搜索验证CE。连续两代没有接受的策略更新属于需要诊断的机制问题，不用更多采集掩盖。
- WAIT统计只在至少存在一个合法PLAY的状态上比较，并另外报告强制WAIT、实际PLAY执行和过早PLAY忽略比例；不添加WAIT惩罚、额外奖励或手写偏好。
- 追加阶段报告独立验证WIN/LOSS CE、Brier、ECE与训练频率常数基线差值。按完整对局bootstrap，不把同局几百个状态视作独立样本。验证集参与选优，因此不能把它当最终未参与选模的留出证据。
- 当开发评测出现明显回归（例如95%成对描述区间上界仍低于50%），保全checkpoint并排查模式过冲、标签视角、教师访问分布和实际动作执行。开发区间不承担当次正式成功结论。
- G8没有达到目标时总结机制证据；若联合更新、直出价值预测和开发胜率仍呈一致改善，可以另登记同配置延长，不设置硬性总训练时长。若基本学习信号缺失，先诊断，不盲目加搜索预算、预训练、奖励或模型。

## 6. 本机历史成本与反馈时点

只读核对历史已完整记录的G1/G2，未把被用户丢弃的G3计入：16局搜索训练均值545.805秒，8局搜索验证均值639.786秒。独立value-only历史64局直出训练均值13.986秒；旧checkpoint对theta0的49局完整评估均值14.995秒。这些分别属于旧三分类运行，不能当作本方案吞吐实测。

按上述均值仅作线性预算参考：

- G1/G2每代4+2搜索局约58分钟；追加32+16直出局约11分钟；一次128局开发筛查约32分钟。首个反馈约为这些采集耗时之和，再加优化、验证推理和运行波动，不能承诺固定完成时间。
- G3起8+4搜索采集每代约115分钟，追加直出约11分钟。
- 首个8轮日程合计56局搜索训练、28局搜索验证、256局直出价值训练、128局直出价值验证、最多512局开发评估。按历史均值仅采集约17.1小时，不含更新/验证推理、故障、正式评估；候选提前出现时可先暂停训练进行正式验收。
- 正式评估128/400/1000/3000局历史线性参考约0.53/1.67/4.17/12.50小时。只有证据足够早停止才能节省这部分成本；不会将理论预算冒作实测速度或保证达标时间。
