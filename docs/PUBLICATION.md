# 公开快照范围

本仓库从工作区独立导出，保留相对目录结构以便追踪脚本之间的依赖。必要内容包括主工程源码、冻结 history-v2 工程、各独立版本根目录的代码/契约/报告、当前规范、阶段进度、测试 XML 和选定历史实验说明。

`publication/source-manifest.json` 逐文件记录原始与公开 SHA-256、字节数和公开变换。发布者新增的 README、维护脚本、检查代码及本说明由 Git 提交标识。

历史 demo_match_set.py 存在内嵌密码默认值；两份公开副本将其清空，继续支持 CR_REMOTE_PASSWORD 环境变量。原始冻结证据仍保留其历史 SHA，公开变换另行登记，不冒充冻结副本原字节。

## 单独保留的附件

- 机器登录配置、真实环境文件、凭据、密钥。
- 原始私有审计、全量对局、权重、优化器状态、缓存、虚拟环境、日志压缩包。
- 第三方游戏二进制与提取资源，以及编译后的 probe。
- 超过 2MiB 的生成文件和非选定多媒体附件。

原始证据内的路径及 SHA 可能指向这些外置附件。公开源码检查与原生重验是不同层次；缺少外部附件时仅复核已公开部分。不得把历史报告存在解释为已重新执行其全部实验。

原工程 LICENSE/NOTICE 保留。原生适配所需的自写 C/C++ 源码、phase snapshot 构建输入与构建脚本在原目录中提供，二进制仍须本地准备。

`native_runner/data/competitive` 的五张压缩 JSON 表是工程原有的编译语义表与模型词表，作为 Python 模块导入和测试的必要输入随源码保留；原始 APK、游戏资产与资源编译输入仍外置。
