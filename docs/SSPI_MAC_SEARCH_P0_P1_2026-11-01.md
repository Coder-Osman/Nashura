# SSPI Mac Pilot：动作协议与首个 1024 搜索根

## 已验证范围

实现了固定 Hog 训练使用的标签式 `WAIT/PLAY/ABILITY` 动作接口、五档 200–1000 ms 出牌延迟、合法动作联合概率、Hog 对 `ABILITY` 的空候选屏蔽，以及稳定八卡身份、四个物理手牌槽和延迟补牌队列表示。2/3 张就绪手牌、补牌到位和快照恢复路径有定向回归测试；这些协议测试没有替代真实对局验收。

PUCT 复用 `fair_final` 的完成边界搜索、FAIR 快照和独立信念世界。搜索接口接受本轮固定的 1024 或唯一对照 128 次有效模拟预算，访问分布只含当前根合法动作。真实根运行使用 ARM64 Android Emulator 中的原生引擎。

## 实测

- 新固定模型有 7,874,126 个参数，权重从种子 `20261101` 随机初始化。
- Apple M4 Max 宿主上的 CPU 与 MPS 正确性探针均产生有限前向输出、梯度和优化步；相同 FAIR 输入的推理数值误差在规格容差内。小型反向优化步中位数为 CPU 0.174 秒、MPS 0.217 秒，本试验选择 CPU。
- 一个真实 ARM64 AVD 根完成 **1024/1024 有效 PUCT 模拟**，总耗时 **712.48 秒**。有效访问数等于预算，未完成边丢弃数为 0；真实根 FAIR 状态在搜索后不变，独立信念世界快照已释放。
- 搜索计时分项：原生模拟转移 495.44 秒、网络推理 94.34 秒、快照恢复 16.62 秒、信念世界建立 1.92 秒。原生转移是当前主要耗时。
- 定向 Python 测试为 **73 passed**；SSPI、FAIR 搜索、rollout 和 runtime 编译检查通过，`git diff --check` 通过。

该搜索根来自开局状态的独立工程验收，记录明确标为 `training_admissible=false`。本阶段尚未完成真实混合策略完整对局、终局 WDL 训练更新、checkpoint 恢复或关闭 MCTS 的独立评估，因此不据此声称训练已闭环或策略已有提升。

## 实现边界

当前实测对应 `sspi-mac-pilot.v1.3`，规格见[训练设计](SSPI_MAC_PILOT_TRAINING_SPEC_2026-11-01.md)。Android ARM64 AVD 是真实引擎宿主；没有使用 Linux VMware。下一阶段继续打通完整对局的 5% 搜索门控、DIRECT/SEARCH 采集、自然终局标签和搜索根训练。
